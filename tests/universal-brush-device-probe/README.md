# Universal brush native probe

Reflection-only instrumentation targeting the exact installed production APK. The UI/model contracts are connected to the universal adjustment-region workflow; the test package contains no production model, filter or dialog classes.

The runner verifies the candidate SHA, installed package bytes, test source/probe provenance, emulator hardware and exact NASA fixture bytes. It temporarily disables network and Android's first-fullscreen coaching prompt, restores the exact prior font/airplane/immersive settings, uninstalls only its test package, and removes only its newly transferred fixture. Evidence is written to `docs/validation/universal-brush/<candidate prefix>/<run ID>/`.

The default `-Flow selection168` covers the persistent-selection policy introduced in 168. It exercises manual brush, one bounds-driven circle/ellipse tool, rectangle, ordered add/subtract, inverse, shape move/resize, feather, undo/redo, cancellation, immediate completion and real saved draft payloads. The display is a separate mask layer: slider down hides it, release restores the user's visibility preference, and the eye toggle changes no edit settings or photo bytes.

The current flow visits the parent regional adjustment, curves, HSL, palette, cleanup, actual detected face and exposed skin, manual face coverage, body range and the legacy radial tool. Nested palette precision and HSV color entry test all three axes with coverage both shown and explicitly hidden. They also test real native window-focus interruption and dismissal while held. These controls remain deferred input: adjusting their widgets does not apply a photo edit. Face/skin→group-chooser round trips retain the display-only eye action. Each final 168 matrix run records 412 checks and 26 original screenshots; reports, hashes and cleanup records define the actual evidence.

Use the explicit `-Mode` and `-Serial` arguments for the owned emulator. The final 168 matrix is phone, tablet, narrow/font1.3 on API36, and landscape/dark. The runner restores font size, display overrides, airplane mode and coaching preferences; the caller owns restoring any dark-mode override it sets. The source APK identity and the smaller signed upload variant are recorded separately; the retained 88 package payloads are byte-identical, with only four obsolete x86 libraries removed for the upload limit.

The explicit `-Flow patch169` exercises the selected-source repair workspace: real target selection/source dragging, rendered exterior/alpha invariants, feather/blend, display-only hiding, gesture/focus cancellation, clamping, delete/clear/undo, outer Apply/Cancel and history, actual v7 saved-draft reload, and current-region reuse. Each final configuration records 278 checks and 13 screenshots, including actual system-bar/cutout bounds. The 169 matrix is phone/API37 plus tablet, narrow/font1.3 and landscape/dark on API36. The exact same APK also runs the 412-check `selection168` regression separately. Reports and hashes define scope; no physical-device or new full-export certification is implied.

The older `all`, `adjustments` and `modal-only` flows are retained for historical regression investigations. Their following descriptions include the pre-168 flashing completion contract and are not current 168 acceptance criteria. Do not run those flashing assertions against a persistent-selection candidate.

Historically, the workflow used real brush/erase strokes and live masks, radius/feather, two-finger navigation and disabled single-pointer anchored scaling. Completion captured the first illuminated canvas, clean gap and second illuminated canvas before PNG encoding; both illuminated frames matched the generated vector mask over the source, maximum alpha was 38 with warm-white RGB, the gap was exact clean source and completion committed one editor history entry.

Every one of the 17 native adjustment controls and the real curves/HSL dialogs is exercised inside the same painted mask. A sampler from the actual installed model classifies every zero-mask pixel, and all those packed ARGB values must remain exact in the actual final preview. Matrix cases are undone to the same baseline so earlier parameters cannot hide a later failure. The workflow then keeps multiple parameters in one region, creates a second independent region, switches scopes without history changes, reopens and cancels/edits/clears masks, undoes deletion, rejects an owner mismatch and checks global/local isolation, real draft/photo switching, full-reference/detail pixels and an independent EXIF6 integer-pixel oracle.

On a separate owned NASA portrait, those older flows use the same real brush over face and clothing. Ordinary brightness must change painted non-skin pixels; five skin controls and a skin-tone preset must leave zero semantic-mask pixels exact. The region context is visible in the portrait title; the old flows expected no persistent overlay during parameter editing. Nested mask cancel/finish/undo/redo retains the full region payload, outer cancel discards the transaction, and outer apply creates one main history entry. Host tests separately own the exhaustive parameter × all-eight-EXIF matrix and alpha0 boundary invariants. The recorded report defines what actually passed.

Do not run until the root agent hands off an owned emulator and a frozen candidate APK. No physical-device or broad image-recognition accuracy claim is made by this probe.
