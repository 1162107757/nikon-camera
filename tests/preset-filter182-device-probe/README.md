# Preset filter 182 native probe

仅在本任务拥有的 Android 模拟器运行。探针加载最终签名的 `cc.huevia`，直接操作 MainActivity 和自定义 Dialog；通过反射提供完整 390 条合成目录与第一页 20 条，替换为隔离的临时本地库，并加入一份经过现有二进制校验器验证的 NP3。不是线上服务验收，也不执行相机导入。

`build.ps1` 使用已构建应用的 classes；`run.ps1` 必须提供候选 APK 路径和精确 SHA-256，并核对已安装包完全相同。配置覆盖 phone、font-dark（320dp 窄屏／1.3 字体）、landscape-dark 和 tablet；运行结束还原显示、字体、主题与飞行模式，移除测试包。探针恢复应用原外观、筛选偏好和原库引用。截图与报告落在 `docs/validation/preset-filter182/device/<apk-sha8>/<run>/`。

覆盖组合过滤、深页已下载 NP3、名称／URL 误导不影响类型、加载中与失败语义、全库计数、目录内分页、搜索交集、分类横轨同值、草稿关闭／返回／重置、版本化恢复、旧格式升级、本地来源下载组隐藏、缓存及删除后在线下载计数。每个原生配置检查所有选择、关闭及操作目标的 48dp 尺寸，检查固定关闭／应用完整可见，并保留原生截图。
