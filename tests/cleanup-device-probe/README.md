# Cleanup 127 and palette v2 native probe

This Android-only instrumentation resolves production classes from the separately installed candidate APK. The runner verifies its exact SHA256 and owned emulator hardware, preserves probe/source provenance, and restores captured system settings independently in `finally`. It does not build the production app, connect to a camera, use private user images or publish anything.

Palette v2 checks the near-square field, actual optical feedback confined to the field, an unchanged photo on a stationary press, direct drag coordinates and a short intermediate movement on a distant tap. Phone saves only three pad Canvas states plus its layout. The separate `animations-off` mode verifies static press feedback and functional drag/cancel/apply without running the cleanup matrix again.

Cleanup uses a uniquely named 3200×2400 synthetic hazy/noisy JPEG, much larger than the editor preview. It exercises real original-file analysis and bounded original patches, a cooperative cancellation and rejected incorrect SHA, actual preview noise variance and contrast, zero-strength identity, cancellation/application/history, actual draft decoding and selected brush-region pixels. A small phone-only EXIF6 fixture has noise on its raw left half and a flat raw right half; after rotation the upper and lower selected regions must sample those distinct noise levels at swapped dimensions. The phone also queues analysis behind a controlled worker block and rebinds to a distinct 2640×1980 synthetic source, requiring stale work to leave the new source untouched. Recipe serialization and mathematical engine regressions are owned by the host engine tests and are not repeated here.

All owned JPEGs and SHA-named private drafts are tracked and removed in the target process after pending saves drain. Each run reports that cleanup result. Pulled native evidence remains under its immutable candidate SHA/run ID until final local/remote hash comparison and deletion of the exact owned remote directories. No user recipe-library record is written.

Run phone, font 1.3, landscape and the short animations-off mode only after the root agent hands over the frozen candidate and exclusive control of the owned emulator. First run one necessary batch; aggregate any defects before a single confirmation batch. Never overwrite old 126 or historical candidate evidence.
