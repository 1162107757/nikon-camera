# 编辑页对比按钮与菜单原生验证

复用 direct-tools133 的 Android API-only 构建、候选 SHA 核对与独有夹具清理脚手架。测试包 cc.huevia.editorchromeqa，只通过反射与当前已安装生产代码交互；入口 chromeFlow。继承的未调用辅助方法不计入本轮断言。

在任务拥有的模拟器上预装最终候选 APK，运行 build.ps1 后向 run.ps1 传 CandidateApk / ExpectedApkSha256 / Mode / Scope ui / Serial。禁止对实体用户手机运行私有夹具脚本。字体与横屏由脚本设置并恢复；模拟平板显示尺寸/密度由外层任务设置并恢复。

验证 48dp 触摸范围、22dp 图标、无文字、实际显示边界；Android 窗口注入按下/松开/移出/取消，核对显示的实际 Bitmap；辅助功能点击和键盘激活处理器、不可用/恢复状态、历史与原图不变。直接检查生产编辑菜单的五个工具项，同时打开真实右上角 PopupMenu，确认照片工具保留而九项重复功能不再出现。保留下方完整调节工具。

本轮聚焦界面精简，不重复 133 已验证的全套算法/导出流程，不把模拟器结果描述为实体设备性能。所有私有原图和草稿按独有文件清理；保存逐轮 APK 身份、探针输入、报告及截图。
