# 直接工具栏原生验证

复用 132 的 Android API-only 反射脚手架与离线 NASA 夹具，测试包为 cc.huevia.directtoolsqa。被测生产代码只来自已安装且哈希匹配的 APK。入口为 compactFlow；未调用的旧人像辅助流程不计本轮证据。

先运行 build.ps1，预装本轮 APK，再向 run.ps1 传 CandidateApk / ExpectedApkSha256 / Mode / Scope / Serial。只对本任务拥有的模拟器使用；不得运行于实体用户手机。font1.3、landscape、tablet 使用 Scope ui，phone 使用 full。tablet 的显示尺寸/密度由任务包装器设置并恢复。

验证完整参数直接可见、17 个参数逐项触达与文字边界、真实横滑、原生窗口注入单点打开曲线/HSL/调色盘/去灰、局部菜单、撤销与局部独立参数、工具切换保留设置、直接人像、简单/高级保存、草稿恢复及预览/导出一致性。每次手势先终止前次合成惯性，触点经 Android 窗口分发，避免绕过滚动容器的测试误报。触达矩形使用 getDrawingRect，包含原生文字按钮的内部 scrollX；直接使用 0..width 会把配方误判为不可达。不会通过放宽文字裁切断言来跳过失败。

完整保存流程截获导出意图并检查目标/冻结草稿，再调用生产渲染器输出 JPEG 与参考 PNG。未执行实体手机 MediaStore 发布。脚本归档测试输入、APK 身份、截图与逐项报告，恢复系统设置并删除测试包；独有私有夹具和草稿由探针清理。

横屏沿用右侧可纵向滚动的工具区，手势触达先展开对应的横向与纵向滚动范围，保留完整控件边界断言。
