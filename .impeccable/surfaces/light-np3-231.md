# 底部光影与 NP3 转换提示

MODE: Operate

沿用现有照片编辑器的深色摄影工具界面，以及相机导入页的白纸与炭灰配色。用户需要直接找到光影工具，并在导入前知道 NP3 哪些效果未带入相机。

- 光影是调节右侧的独立底栏分类，使用既有 brightness 图标；四种光影样式及原有编辑、保存语义不变。
- 转换差异显示在原有覆盖槽位确认页；说明保留、近似和忽略项，继续使用同一个确认写入按钮。
- 不支持的效果只提供说明。损坏文件、失效会话和不一致的槽位另按已有错误流程处理。
- 已检查 Android 320×720 与 1024×768、1.3 倍字体的真实渲染；手机底栏完整可见，提示页可滚动，确认按钮可达。
- 证据见 `docs/migration/validation/light-np3-231/screenshots/`，照片为明确标注的合成布局测试图。
