# 编辑草稿恢复与工具样式统一（152 / 0.29.1-beta）

修复普通打开照片始终使用 savedOnly=true、跳过未导出草稿的问题。现在 bind(photo) 恢复该原图哈希与当前账号下的 pending draft；只有明确选择照片版本时才使用 bindSavedVersion(photo)。关闭、返回相册和页面释放继续刷新待保存任务，同一照片经手机相册重新导入也保留草稿身份。关闭保存编辑参数；JPEG 导出仍使用既有新副本流程。

重置按钮不再依赖空文字 Button 的左侧 compound drawable，图标和底色共用目标中心。圆形底色以目标短边定半径，按下／焦点状态保持同心；主工具选中背景也在同一圆形中绘制。主编辑页恢复关闭旁的三点菜单，保留收藏、直方图、照片版本、全部滤镜、快速优化、配方、精细构图、细节、复制／撤销复制、重置等实际能力与条件。

皮肤、面部、塑形，以及曲线/HSL、调色盘、去灰、局部、涂抹、精细裁切使用同一照片氛围、黄色主操作、白色滑块和圆形工具。肤色选择器、光照定位、边框、直方图、细节和导出预览等编辑部件的旧强调色同步为黄色。未替换照片本身的颜色或色卡数据，未改处理算法和子编辑器的应用／取消事务。
