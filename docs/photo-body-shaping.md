# 人像塑形（128 / 0.25.0-beta）

入口为「调节 → 人像 → 塑形」。塑形与皮肤、面部并列，沿用图标加文字入口。区域人像页继续提供皮肤与面部；塑形在全图人像中操作。

## 使用

- 瘦身、瘦腿、腿部拉长分别保留强度和范围。初始强度为零，不会自动改变身材。
- 拖动范围框内部移动，拖动边角或边缘改变范围；也可展开「范围」使用左边、上边、宽度、高度滑块，支持键盘和辅助功能。范围框是影响范围，需要用户放到相应部位，没有新增自动人体姿态识别。
- 瘦身的上边放在肩部以下。瘦腿默认双腿，中线对齐两腿之间；也可切到单腿，把框放到一条腿上。
- 腿部拉长的上边对齐大腿根，底边对齐脚底；脚下需有留白。它保持上方位置与画布边缘，通过脚下空间吸收变化，不增加照片尺寸。
- 滑动强度时隐藏辅助框；松开恢复。照片下方的范围按钮可随时隐藏或显示。双指缩放查看，按住对比显示进入塑形前的效果。
- 点击强度数字可输入 0–100。重置当前工具不清除另两项。子页内可撤销、重做；返回取消本次塑形，应用先记入人像工作区的一步撤销，再由人像「应用」提交到主编辑器。

## 与其他调节配合

全局颜色、局部蒙版、肤色、面部与祛痘先在原有坐标处理，塑形在这些步骤后执行，最后再裁剪、透视和加边框。已有笔触及处理结果随塑形一起移动。

塑形生效后，进入需要定位的人像子工具、涂抹或局部工具时，显示并标明「塑形前定位」的画面，以保持自动识肤、人脸、取样修复和笔触一致。退出定位工作区后恢复塑形预览。主画面的按住显示选区会使用同一塑形映射，显示变形后的选区。

## 数据与处理

- `PhotoBodyShape` 为不可变数据，每项独立强度与归一化范围，另有单腿模式。零强度但调整过的范围仍保留在草稿和版本身份里。
- 仅有塑形状态时使用人像 wire v5；没有塑形状态仍写 v4，旧人像和局部格式继续读取。照片配方只保存全局颜色，沿用原规则，不把人体范围跨照片复制。
- `PhotoBodyWarp` 组合三项逆映射后只采样一次，使用预乘 alpha 的双线性插值。未被映射改变的位置保留完整 ARGB；强度全零直接跳过。
- 水平方向使用在范围边缘平滑归零的收缩场；双腿分别收缩。拉长使用上下端平滑衔接的垂直位移，最高位移受腿长和脚下空间共同限制。所有范围边缘与照片边缘保持连续。
- 读取与写入不会互相污染：原像素临时保存到应用私有文件，行缓存上限约 16 MiB，暂存上限 512 MiB，取消或异常后删除临时文件。预览与完整导出使用同一处理入口，EXIF 1–8 均转换到同一朝正坐标计算。

## 使用边界

这是用户定位的局部变形工具，不含背景重建或人体分割。强度较大、范围过宽时，附近衣服和背景也会变形；斜腿、交叠腿可使用单腿模式处理选中的一条腿（当前只保留一组瘦腿范围）。脚下空间较少时，可拉长的幅度相应减小。本轮验证使用自制合成图和数值夹具，尚未进行用户真实照片效果验收。
