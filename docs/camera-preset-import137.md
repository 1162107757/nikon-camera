# 统一预设与可选机身参数

版本：0.28.0-beta（137）。当前相机写入通道限定为 Nikon Z6II，支持 USB、Wi-Fi。

## 预设展示和导入

- 在线预设、我的预设统一展示，保留风格分类，移除格式筛选和格式徽标。升级后清除旧格式筛选，避免隐藏预设。
- 原文件、扩展名、格式元数据、源 SHA-256 保留，不覆盖原文件。
- 已支持的传统彩色配方沿用兼容转换；导入前选 C1–C9，覆盖已有槽位仍需再次确认。
- 已解析的灵活色彩配方可选择部分适配：使用自然基底，保留锐化和明暗曲线；色彩混合器、分区调色、全局饱和度不导入。已有曲线逐字节保留，没有曲线时提取手机模拟的明暗曲线。
- 已解析的单色配方可选择部分适配：标准单色基底、明暗曲线和锐化；专用单色响应、滤镜、调色及浓度不导入。
- 现代配方的中等范围锐化、清晰度默认取原值，也可调整。用户修改适配值后需重新接受差异。
- 部分适配在确认页列出差异，默认不勾选接受。没有明确接受时，界面和后端均禁止写入。
- 未识别版本、基底、字段或损坏文件不猜测转换。保留源文件；手机套用也取决于现有解析器是否支持。

## 拍摄参数

“拍摄参数 → 选择”提供白平衡、指定色温、曝光补偿。三项默认均不调整，色温只在选择“指定色温”时出现，可随时恢复“全部不调整”。这些值由用户选择，不会从混色器、局部修饰等参数推断。

所选值影响后续拍摄，与 C1–C9 内的 Picture Control 数据分开处理。导入不会自动切换当前 Picture Control；仍需用户在相机选择目标槽。

执行顺序：

1. 重新计算并核对源文件、用户确认的适配数据 SHA-256。
2. 核对型号和相机操作能力，完整读取槽位，并在写入前再次核对目标槽。
3. 只发送一次预设登记，精确读回核对。
4. 若用户选择了拍摄参数，读取新鲜的属性描述、当前值、可写标志和枚举/步进范围。
5. 将调整前原值和目标值写入持久记录，保存校验成功后才授权属性写入。
6. 写入前复查参数及模式；每个属性只允许本次确认的确切值尝试一次，随后读回核对。色温依赖的白平衡模式也会复查。

不支持、只读、值不在允许范围、确认后被用户改变的项会跳过。结果逐项显示调整前/目标值、成功、跳过、拒绝或未核对状态。预设成功和参数结果分别呈现，不把部分成功说成全部完成。

即时结果页与连接状态通知共用完整结果；USB 无需等待连接租约结束通知，也会直接显示参数结果。确认页“调整”“选择”的触控范围至少为 48 × 48 dp，文字保持紧凑。

超时或断连后不自动重试，也不自动回滚。报告保存参数原值；发生进程中断后，只读恢复会明确提示拍摄参数需在机身核对。当前未提供一键恢复原值。

## 验证与限制

- 主机测试覆盖原文件不变、曲线保留、近似转换授权、确认哈希变化、非法字段、符号/范围/枚举、默认不改、只读参数、状态竞争、写入拒绝、读回拒绝/不一致、连接中断与禁止重试。
- USB 使用实际生产传输层和合成相机验证完整流程；Wi-Fi 使用合成双 socket 验证参数封包、单次授权和登记后的会话移交。
- 原生界面探针只运行于模拟器，使用合成预设/槽位，检查默认关闭、同意差异、参数保存及重置、旧筛选迁移。不会连接或修改真实相机。
- 尚需 Z6II 真机验收各拍摄模式、参数支持和实际拍摄效果。部分适配未经过尼康色彩等效认证，不能恢复完整灵活色彩。
- 更多机型、更多参数、配方附带推荐拍摄值、一键恢复原值未在此版本实现。

协议代码依据：[libgphoto2 Nikon 属性编号](https://github.com/gphoto/libgphoto2/blob/master/camlibs/ptp2/ptp.h)、[白平衡枚举](https://github.com/gphoto/libgphoto2/blob/master/camlibs/ptp2/config.c)。实际允许写入的类型、值及模式始终以当次机身描述为准。

测试入口：`tests/run-probe.ps1`、`tests/camera-preset-host/run.ps1`、`tests/run-ptpip-download.ps1`、`tests/camera-preset-device-probe/build.ps1`。
