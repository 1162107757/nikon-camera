# 照片操作菜单与滑杆端点（136 / 0.27.4-beta）

更多菜单改用简短名称与图标，按照片操作、批量调色、重置分组。直方图显示当前状态；收藏显示收藏或取消收藏。长解释只用于会改变编辑范围的操作，例如重置调色保留滤镜与人像，还原原图清除全部编辑且可撤销。原有照片版本、真实像素细节、复制和撤回、草稿恢复、删除仍使用既有回调，没有新增重复的底部工具入口。

菜单为锚定到更多按钮的深色圆角浮层，字号随系统放大、行高随内容增长。短屏中限制到实际安全屏幕高度，并可纵向滚动；支持返回、点击外部关闭、键盘焦点和读屏。照片/账号变化或原按钮移除后不继续执行旧菜单回调。

底部滑杆原先的 3dp / 8dp 水平 padding 小于原生圆点所需空间，导致两端裁切。现在根据原生 thumb 的宽度与偏移保留两侧空间，并增加 2dp 余量；原来更大的留白保持。没有改变最小值、最大值、滑杆偏移或业务监听器。

修正覆盖优化强度、人像快捷强度、调节参数与滤镜强度。顶部 1/1 继续表示当前第 1 张、列表共 1 张；本轮只解释含义，没有更改它。

安装包仅本地保留，未上传或发布。
