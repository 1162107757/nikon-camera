# 照片调色盘

在照片编辑器进入「调节」，点击「调色盘」。入口与人像、局部、曲线、HSL 使用相同的图标加文字样式。

在色板上拖动白点，可同时调整两个方向：

- 左右为颜色浓淡，范围 -100 至 +100；左侧更清淡，右侧更鲜艳。
- 上下为影调对比，范围 -100 至 +100；下方更柔和，上方对比更强。影调曲线保留黑白端点。

下面的强度控制整体效果。强度设为 0 时画面恢复到进入调色盘前的效果，选择的坐标仍会保留。点击颜色、影调或强度的数值可以精确输入；重置恢复中心点和 100% 强度。支持撤销、重做和按住对比。

手指移动时立即更新白点和数值，并通过现有预览队列更新小图；松手后计算完整预览。一次拖动对应一次调色盘内部撤销。取消或返回不修改主编辑器；应用后只增加一条主编辑历史。未完成最新预览时，应用按钮暂不可用。

面板打开时以 180ms 轻柔滑入；白点按下时轻微扩张，松手后用 140ms 收回。重置、撤销、精确输入等操作会以 160ms 平滑移动白点，真实手指拖动仍直接跟手，随时可以打断过渡。照片画面不参与装饰动画。系统关闭动画时，全部反馈立即显示为静态状态；中断、失焦或关闭会清理动画。

调色盘参数独立于现有手动滑杆。它在滤镜与已有手动颜色调整之后处理颜色；暖色增加饱和度时采用更小的增益，已鲜艳的颜色减少额外增强。此处采用 Huevia 自身的色彩算法，操作形式参考二维颜色／影调控制。

主编辑器选中「全图」时调整整张照片，选中涂抹区域时仅调整对应区域，区域边界沿用现有羽化蒙版。参数随草稿、保存版和配方保存；复制调整中的颜色分类包含 HSL 和调色盘。调色盘本身不记录涂抹范围到配方。

兼容规则：未使用调色盘的草稿、配方与区域继续使用旧格式；有调色盘状态时，全图草稿使用 PED7、配方使用 PRC4、含调色盘的局部编辑使用 v4。新版本可读取原有格式。默认状态与零强度不增加像素处理；没有引入模型、原图缓冲或额外网络请求。

版本：126 / 0.24.4-beta。本次仅新增照片「调节」功能。
