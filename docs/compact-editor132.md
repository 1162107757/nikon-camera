# 简化照片编辑（132 / 0.27.0-beta）

按用户在交互原型里最后选中的「紧凑工具区」实施。沿用黑色照片画布、桃色动作、系统字体和图标加文字入口。

## 日常路径

照片列表提供可见的「选择」「添加照片」，手机竖屏采用两列照片，文件名继续保留在无障碍描述和照片操作中。手机来源权限、App 内原图/效果版本、长按多选、批量处理和横屏布局仍使用原有数据路径。

编辑主入口为「优化、滤镜、人像、调节、裁剪」。普通工具使用相同面板高度，避免切换时改变照片画布；构图保留独立的裁剪、旋转、拉直和透视工作区。撤销、重做和按住对比原图显示在共用工具行。照片细节、直方图、收藏和版本通过顶部更多操作访问。

- **优化**：原图、自然、通透、人像四个快捷选择。自然和通透组合现有去灰、降噪及少量明暗/鲜艳调整；人像重新识别本张皮肤与面部，再使用自然精修。原图会清除当前编辑，可撤销。
- **人像**：直接提供自然精修、皮肤、面部、塑形。皮肤与面部进入对应工具，返回直接回到主编辑页；塑形直接打开自身工作区。
- **调节**：默认显示亮度、冷暖、对比、鲜艳。精细入口保留更多参数、曲线、分色、调色盘、去灰细调、局部涂抹、边框和我的配方。

快捷选择写入既有编辑参数，不增加数据格式或渲染模型。快捷包明确设置自身使用的亮度、对比、自然饱和度及去灰参数，保留其他参数；人像快捷项设置自然精修强度，保留手动细修。重复套用不累加，强度可回到零，整次手势可以撤销。重新打开时按实际参数识别快捷项；这些参数已被单独微调后显示已有调整，避免错误标记。

识别过程显示处理中并暂时禁用保存。切换照片、账号、重置、更新的快捷选择或其他编辑使旧结果失效；工作完成前核对原图字节。识别失败不提交半成品。

## 保存

保存先显示底部面板：当前效果、原画或适合分享、保存到手机相册。尺寸来自实际成品计算，分享沿用长边 2048 的上限规则，不放大小图。「更多设置」打开原有完整导出界面，包括自定义尺寸/质量、保存位置、已保存检查、成品预览和原始文件入口。

快捷保存明确选择手机相册和新副本；进入保存面板时冻结当前照片、完整草稿、账号和源文件身份，确认时再次检查。批量保存沿用逐张草稿和规格计算，不复制第一张的效果覆盖其他照片。

原图文件保持不变；草稿、细节预览和完整尺寸导出沿用既有处理管线。新增界面不上传数据，也不发布更新通道。
