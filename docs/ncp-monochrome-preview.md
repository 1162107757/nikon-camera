# NCP 0100 单色预览

0.24.1-beta / 123 为旧格式 NCP 0100 增加独立单色手机近似模型。此前 2026-10-27 导入的 149 个原件中，130 个彩色文件可预览，19 个使用 Monochrome 基底的文件被预览器拒绝。原文件和线上目录无须改写。

`NcpMonochromePreviewProfile` 严格校验 638 字节容器、版本、基底、记录长度、有效参数及 257 个曲线采样。支持 Off、Yellow、Orange、Red、Green 滤色，以及本批实际使用的 B&W、Sepia 和 Yellow 调色。未知或损坏的参数仍明确拒绝，不生成替代原图冒充效果。锐化只保留为元数据，与原彩色 NCP 预览的处理边界一致。

各文件的原始曲线参与处理，单色滤色、色调与浓度分别进入新模型。B&W 输出灰度，调色预设保留各自色彩；滤镜强度继续混合完整处理结果。模型是 App 的 RGB 近似，不能代表相机 RAW 管线或厂家颜色等效。具体数值依据、实测误差和未测边界随本次验证结果记录。

色调数值来自同一隔离 RAW 的 NX Studio 内置 MC 对照：Off、Sepia 浓度 4、Yellow 浓度 4，关闭曲线，空间参数、对比和亮度归零，使用相同尺寸和 ICC 的 16 位 TIFF。新模型用每通道二次色偏近似调色响应，修正了临时模型的 Sepia 绿色方向。保留既有单色基底后，整条近似流程在这张图的采样平均绝对误差为 Sepia 1.87、Yellow 1.93，局部最大误差为 16.21、15.94，单位均为 0–255 浮点值、未包含最终 8 位量化。这是单图诊断，不是独立照片验证或相机匹配结论。

滤色灵敏度是 App 的 RGB 设计值，浓度 1–7 使用相对浓度 4 的线性缩放；这两项及自定义曲线只验证功能，未与 NX 全参数逐项测量。校准依据、系数、误差和边界见 [主机验证记录](validation/ncp-preview123/HOST-SUMMARY.json)。

原彩色 NCP 与已有 NP3 单色、Flexible Color 等模型的算法和身份保持不变。组合模型版本加入新单色身份，使旧“不支持”缩略图缓存自动失效，已经导入的同一条预设可以直接预览。详情、图库、滤镜选择、调节草稿和导出共用同一解析入口。

编辑器将临时读取、下载及渲染错误标记为可重试；真正的参数不支持仍显示原因，避免反复加载。点按重试恢复同一条记录，不需要重新导入。

原生验证同时发现“在线 / 我的”切换的独立生命周期问题：旧面板异步关闭时无条件清空共享的网格字段，可能让新面板的缩略图保持空白。显式关闭现在同步保存滚动并释放当前字段；异步关闭回调只清理仍由它自己持有的面板，不能清空后来的面板。验证覆盖实际按钮双向切换，且保持选择与撤销状态。

验证资料保存在 [NCP 123 验证目录](validation/ncp-preview123)。私有 RAW 和 NX Studio 导出仅在被忽略的本地校准目录处理，不进入安装包、公开验证图片或发布附件。
