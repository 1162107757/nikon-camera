# 紧凑底部与顶部操作（135 / 0.27.3-beta）

普通字号下，优化、人像、调节的底部高度从 300dp 减到 244dp，减少约 19%。其中内容区由 204dp 减到 148dp；撤销、重做、原图对比和分类仍保留 48dp 的可触摸行。

调节将参数名、滑杆、精确数值及选区入口放进同一行；17 个参数与曲线、HSL、调色盘、去灰、局部继续直接横滑使用。区域名称较长时显示完整无障碍说明与提示。滑杆本身的触摸高度扩大到 48dp，不通过压小触摸范围节省空间。

优化的四张照片卡片与强度共用紧凑布局；人像的自然强度也合成一行，下方保留自然精修、皮肤、面部、塑形四个入口。滤镜、边框、配方内容区为 176dp，给缩略图/列表保留必要空间；裁剪仍为 112dp。工作区内调参数不改照片画布高度，切换到浏览工作区会使用其额外 28dp。

顶部移除“编辑照片”的两行通用标题，改为左侧返回与横向更多、中间照片序号、右侧图标加保存。左右预留对称，序号居中。保存使用柔和深暖色表面和桃色文字/图标；处理状态时收起图标以显示文字。更多菜单采用编辑器深色主题，并保持 134 去重后的功能。

照片、保存规格、草稿和渲染逻辑不变。本地试用，不上传或发布。

横屏右侧工具区使用内容自身高度，可在需要时滚动；不将工具背景强行拉满剩余高度，分类仍固定在下方。
