# 相册悬浮选择栏实现

版本：0.28.4-beta（141），本地测试包。对应用户已要求开始实施的 `docs/design-review/album-floating-selection-20261105/` 设计稿。

已授权手机页直接浏览当前可访问的 JPEG/PNG，移除常驻“选照片”。未授权空状态保留“允许访问照片”和轻量的“选择指定照片”；部分授权继续显示范围标记并保留更多菜单管理。

选择模式使用同一条 56dp 悬浮毛玻璃栏替换导航，隐藏顶部总量操作行与更多按钮。标题保持“相册”，来源锁定，选中数量只显示一次。手机为“取消 / 已选 x 张 / 批量编辑”，App 内为“取消 / 已选 x 张 / 保存 / 编辑”。保存和编辑仍走既有流程。

栏外圆角 28dp；主按钮点击高度 48dp，可见背景高 44dp、圆角 22dp，四周视觉间距 6dp。操作 13sp、数量 12sp，窄屏数量 11sp，次要操作沿用同一灰色。左右距内容 16dp，底部在系统安全区内额外留 14dp；大屏居中并限制宽度 420dp。旧系统、低内存或性能策略不允许模糊时，复用 GlassBar 的实色回退。

照片选中标记改为 22dp 圆形勾选及细边框，整张照片仍是点击目标。选择时不缩放缩略图；横屏冻结当前列数，大屏隐藏导航时保留原有网格对齐。列表末尾为悬浮栏预留滚动空间，最后一张照片可完整滚到栏上方。

取消和系统返回手势都退出选择并恢复导航。准备中显示紧凑状态，取消会使旧导入请求失效。保存设置取消后保留选中照片。修正了保存流程内部暂存选择状态影响相册导航恢复的问题：返回与顶部导航以当前可见界面为准。Android 13+ 仅在此选择模式注册平台返回回调，退出与销毁时注销；旧版本保留原返回路径。平台 API 依据 [Android 返回迁移文档](https://developer.android.com/guide/navigation/custom-back/predictive-back-gesture)。

## 验证范围

最终八个模拟器配置：默认、大字体、深色、大屏视口、横屏、未授权、部分授权及 320dp 窄屏大字体。报告见 `docs/validation/album-floating141/final/`，共 736 次断言执行（不是 736 个独立场景）。

验证了单行和 48dp 点击目标、空选择禁用、来源锁定、照片尺寸保持、取消恢复导航、真实系统边缘返回手势、准备状态取消、最后照片避让。实际打开并取消保存设置，确认保留选择；实际准备三张自有手机 JPEG 并进入原批量处理菜单；未授权替代选图验证真实系统 Intent 分发及取消。

早期检查发现保存暂存状态干扰导航，已修正并保留初始记录。旧式按键注入不代表本模拟器的手势返回路径，最终使用系统边缘滑动验证；保存弹窗及批量菜单分别通过真实取消按钮关闭。最后一次 APK 构建后已完成全部配置，未改动生产源文件。

全部照片为自有测试夹具，使用只读 Android 模拟器。未提交真实照片保存，也未进行相机或服务端写入。部分工作副本仅产生于可丢弃的模拟器中。没有连接实体手机，真实设备效果、旧 Android 设备与相机验收仍待进行。
