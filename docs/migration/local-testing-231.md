# 本地测试版 231：底部光影与 NP3 兼容导入

本轮产物是本地 Android ARM64 候选，尚未线上发布。它基于 230 的六项功能，新增以下调整：

- 照片编辑底栏为「滤镜、调节、光影、裁切、人像、边框」。点击「光影」直接打开柔光、侧光、聚光、阴影；更多菜单中的重复入口已移除。
- NP3 导入相机时，将能识别、能表达的参数转换成 NCP 0100，并构造经过校验的相机登记数据。手机无法预览某个 NP3，不再作为相机转换的拦截条件。
- 写入前在原有槽位确认页列出保留、近似转换和不导入的内容。用户可继续导入兼容部分，仍须明确确认目标槽位。

## 转换范围

有效且兼容的原始自定义曲线逐字节保留。已识别的锐化、饱和度、色相按 NCP 可表达的整数档转换；中范围锐化和清晰度通过已有相机兼容登记字段写入，默认保留 NP3 中可识别的值，用户主动调整后采用手动值。

灵活色彩改为自然基底。没有存储曲线时，已识别的对比度、高光、阴影、白色和黑色合成近似明暗曲线，并明确提示近似；这不等于恢复 Nikon 的完整色彩算法。深色调单色改为标准单色。其他未知基底改为自然，并说明差异。

灵活色彩全局饱和度、混色器、分区调色、专用单色响应、创意效果强度、Quick Sharp 联动及其他当前无法表达的效果会被跳过。自动、未知或超出兼容范围的数值采用说明中的默认值，不阻止其他参数导入。未知版本布局只提取能够独立核实的内容，并提示其余部分不可用。原 NP3 始终保留。

结构损坏、记录越界、重复记录、缺少终止标记或超过 1 MB 的文件仍会报错。账号、相机会话、槽位快照、覆盖确认、单次写入和写后读回的保护保持有效。

## 验证

- 2073 项共享核心边界检查及 6 项光影氛围检查通过。其中新增 59 项 NP3 转换检查和 11 项实际导入协议边界检查。
- 当前目录内 47 份不同 NP3 样本全部转换通过，其中 11 份不能由手机预览器渲染。检查了有效 NCP、相机数据范围、原始文件不变、曲线保留及不支持项提示。未将这些第三方样本打入应用。
- Android API 31 x86_64 上 10 个场景通过：9 个相机槽位界面场景，以及底部光影和 NP3 确认界面场景。320/1024 宽度、1.3 倍字体的截图已检查；确认按钮可达。
- Windows 定向的更多菜单 4 项、编辑入口与操作 7 项、光影控制 3 项通过。全量 Windows 测试发生 `flutter_tester` 原生访问冲突，存在未完成用例，不能记为全量通过；负载下失败的一项旧下载时序用例单独重跑 7/7 通过。相机槽位界面在 Android 上完整复核。
- APK 的 ARM64 运行库、RAW JNI/R8 回调、包名、版本号和签名已核对。签名与已发布的新版 229 相同。模拟器已恢复原有 230 普通测试包，未清除应用数据。
- 本轮未连接实体 Z6II，未构建 iOS 231；不能将软件模拟和 Android 界面检查当作实体相机或 iPhone 的验证结果。
