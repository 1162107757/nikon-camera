# 原 Android 样式验收范围

要求保持原 Android 186 的布局和交互，不以默认 Material 控件替代原版设计。视觉基准为冻结工程 `6fb5003` 和同机安装的 `0.30.32-beta+186`；共享版布局检查见 [Android 188 截图与记录](validation/style-android12-188/README.md)。

“已对照”表示已安装、操作并检查指定状态，仍须处理字体栅格化、取整和下表列出的差异；不表示整项逐像素一致或功能已全部迁移。页面中尚未支持的能力继续列在完整迁移范围内。

189 实装复核增加了 [外观弹窗的同状态截图和失败记录](validation/style-android12-189/appearance-review.json)：两端均选浅色，原版选项区域为 `42–1038 px`、行高 `126 px`，共享版为 `173–908 px`、行高 `147 px`；标题、取消按钮、字重和单选标记也未对齐。此弹窗仍未通过，不计入已还原页面。

190 后续已将外观选项区域改回 `42–1038 px`、行高 `126 px`；预设筛选与相册排序的底部操作区均可点击，不再被根导航覆盖。见 [190 对照与实际在线库截图](validation/controls-online-190/README.md)。189 记录保留为修复前证据；190 仍有少量标题和文字度量偏移，完整逐像素验收继续保留为未完成。

200 在同一模拟器、同三张自制照片和手机来源状态下复核选择页：原工具条边界 `74,1993–1006,2161`，共享版 `74,1994–1006,2162`；取消按钮边界一致。来源禁用态、选择数量、原铅笔图标和操作区已调整，横竖屏/双倍字体场景通过。来源标签字重、日期文字约 2px 的偏移及缩略图采样仍待对齐，见 [200 对照截图](validation/gallery-batch-200/README.md)。


202 已对照原 186 重新实现边框设置和机型面板、主构图入口与构图页，并补回成品预览深色系统栏及完整分段选中背景。边框设置区域为 `0,1017–1080,2214`，滑杆行高 `126px`，构图入口行与操作行位置已对齐；控件测试及 release 实操通过。模板卡片仍有设备像素取整造成的约 1px 差异，部分字体回退和全部状态仍须继续核对，不能认定整体逐像素通过。参见 [202 原版/最终 release 截图与范围](validation/editor-workspace-202/README.md)。

204 正式包自查又发现四模板缩略图可能持续空白，实际反馈为“该任务正在执行”。现修复 Android 完成回调清理顺序、每张缩略图的独立标识，以及临时忙碌后的恢复。修复前后截图、2400万像素 EXIF6 图片和编码预览取消返回的实操见 [204 验证](validation/account-profile-204/README.md)。原四模板和设置样式保留；其余视觉差异不因此改为全部通过。
