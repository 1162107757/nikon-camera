# 原 Android 样式验收范围

要求保持原 Android 186 的布局和交互，不以默认 Material 控件替代原版设计。视觉基准为冻结工程 `6fb5003` 和同机安装的 `0.30.32-beta+186`；共享版布局检查见 [Android 188 截图与记录](validation/style-android12-188/README.md)。

“已对照”表示已安装、操作并检查指定状态，仍须处理字体栅格化、取整和下表列出的差异；不表示整项逐像素一致或功能已全部迁移。页面中尚未支持的能力继续列在完整迁移范围内。
