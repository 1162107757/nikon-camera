# 本地测试版 232：光影 B 菜单

光影二级菜单已改为用户选定的 B 方案：四个圆形图标位于名称上方，选中项为黄色，进入后替换一级栏并扩大照片预览。返回可恢复一级工具栏；三个参数、重置、对比和应用保留。侧光显示方向，其余效果显示范围。

安装包：`dist/migration232/huevia-0.31.0-dev-232-android-arm64.apk`。包名 `cc.huevia.next`，Android 8.0+、ARM64，版本 232，与新版既有证书相同。准确字节数和 SHA-256 见该目录的 `ARTIFACTS.json`。

Android 模拟器 11 个界面场景及五个本轮 Dart 文件静态分析通过，手机、大字体小屏和平板已截图检查。Windows 全量运行器未完成，不记为全绿。人像模型、RAW JNI/R8、安装包签名和资源完整性已核对。

这是本地开发测试包，未线上发布；iOS 232 与实体相机测试未执行。此前 230 Android/iOS 与 231 的冻结安装包保持原样。完整记录与截图见 [光影 B 验证](validation/light-menu-b-232/README.md)。
