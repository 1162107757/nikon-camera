## 214 人像重点测试

准备一张清晰单人照片、一张至少两人的照片；如有条件，再用带小红色瑕疵和暗色痣的照片对照。NEF 先完成显影，再进入“人像精修”。初始底部为“皮肤 / 面部 / 塑形 / 自然精修”，不是同时铺开的参数长列表；横屏也应保留照片与可操作的工具区。

1. **选脸与更多入口。** 进入“面部”，点照片上缘“自动选脸”；已有脸时重新识别须确认。用“选择人脸”锚定菜单切换人脸，也试手动添加。人脸栏最右三点为“更多人像操作”；全图肤色模式下，从肤色控制行的“更多肤色选项”打开对应菜单。
2. **普通调整与撤销。** 选择一个面部工具，拖动单项滑杆并观察照片；试“撤销 / 重做”、显示或隐藏选区、适应照片、按住对比。松开或取消对比后回到当前处理结果。双指缩放 / 平移后，仍能正确点脸、祛痘和画区。
3. **选区刷。** 从照片下方画笔“涂抹范围”进入原选区工作页，画笔选定范围；分别试取消与“完成”。在人脸选区工具中试“选脸 / 补选 / 擦除”，并核对范围覆盖。双指导航应取消本笔候选，不把缩放手势写成画笔。选区内调整只影响所选区域。
4. **自然精修。** 从分组或皮肤工具进入“自然精修”。应先做真实人物分析；已有非零强度保留，否则从原版强度 50 开始。检查皮肤效果与人脸分析结果，再撤销；未识别成功时不得假显示已完成。
5. **肤色色卡与候选。** 在“皮肤 → 肤色”选择原色、预设或“自定义”。自定义可调色相、饱和度、明度，也可“照片取色”；“预览效果”后分别试“取消 / 使用此色 / 继续选色”。保存个人色卡后，换照片核对可复用；删除卡不应更改照片已使用的颜色。
6. **逐人全身肤色。** 用多人照片在肤色更多菜单切到“逐人肤色调节（高级）”，选定一人后比较“仅脸部 / 全身皮肤”。全身范围需先分析该人的身体皮肤，核对另一人及背景是否保持不受影响；切换到另一人再试。分析失败不能被当作已完成全身调整；再切回“全图肤色调节”核对当前颜色与强度。
7. **自动祛痘。** “皮肤 → 自动祛痘”先分析皮肤，再显示“修复疑似小瑕疵”。候选默认全选，可取消其中一处；“取消”保留原状态，“修复所选”只处理确认候选，并可一次撤销整批。无合适候选时应有说明；暗中性痣不应被当成必须去掉的瑕疵。
8. **塑形与事务。** 进入“塑形”，试瘦身、瘦腿、腿部拉长与背景保护，拖动所选范围边框；点强度数字试 0–100 精确输入，展开“范围”调整左边、上边、宽度、高度，再试“重置”只恢复当前塑形项。在瘦腿中切换单腿 / 双腿；分别试本页返回 / 取消和应用。取消恢复进入塑形之前的状态；确认后仍可在人像页撤销。最后试整个人像页“取消”与右上“应用”：只有应用才把本次人像结果带回照片编辑器，原始照片文件保留。

### 更多菜单 7 类逐项核对

菜单按原 Android 条件显示：没有人脸或祛痘记录时，对应操作禁用；“管理个人色卡”和全图 / 逐人切换只出现在肤色工具。空色卡库时管理项禁用，先从“自定义 → 保存色卡”保存一张。

| 菜单项 | 操作与预期 |
| --- | --- |
| 逐处撤销祛痘 | 有多处点按或已确认自动祛痘后，按坐标列表选择一处撤销；其他祛痘保留 |
| 管理个人色卡 | 选择“删除 · 名称”，取消时保留；确认删除后库中移除，照片已用颜色保留 |
| 逐人肤色调节（高级） / 全图肤色调节 | 两种模式互切，当前肤色、强度与目标范围按原行为衔接，不能只换标签而丢失颜色 |
| 停用此人脸 / 启用此人脸 | 停用时该脸的调整停用、滑杆不可继续改；重新启用后保留已有参数 |
| 删除此人脸 | 仅移除选中的脸；其他脸、既有祛痘和原图保留；可以撤销 |
| 撤回上一处祛痘 | 只撤回最后一处祛痘，不是删除最后一块自动修补 patch |
| 重置人像精修 | 先显示原确认说明；取消不变，确认清除该人像事务的肤色、磨皮、面部、塑形、选区修正与祛痘；仍可撤销，不删除原图 |

## 从旧 Android 带入资料

保留旧应用，在其上覆盖安装同签名的 [旧版资料迁出辅助包 194](../../dist/migration213/huevia-0.30.34-legacy-export-194.apk)，从新增的“旧版资料迁出”入口保存 ZIP；原应用入口继续保留。194 是旧包的独立手动安装工具，不是新版 next，也不通过旧更新通道分发。安装失败时不要通过卸载或清数据来绕过。

在 Android 214 的“设置 → 旧版资料迁入 → 选择资料导出包”选择 ZIP，核对清单后点“迁入已核对资料”。已有资料保留；需要撤回时在记录中点“撤回”。迁入后若又修改了受管资料，自动撤回会停止并提示，避免覆盖新修改。旧安装与导出 ZIP 都保留。

iOS 的旧资料仅按真实可导出的文件导入：旧 App 已暴露的 Presets 目录可从 Files 选择；不承诺读取另一个 App 的私有 sandbox 或 Keychain，账号关联也不迁移旧凭据来自动登录。
