## 本次重点：我的预设长按菜单

准备两款可重新导入的本地测试预设，并在 Android、iOS 分别操作。

1. 打开「我的预设」，**长按**其中一款。应出现紧凑圆角菜单，显示所选预设名称，提供「置顶」与「删除」；已置顶的预设提供「取消置顶」。浅色 / 深色主题、较长名称、大字号和窄屏下都应能看清并操作。
2. 点「置顶」应直接回到列表并更新置顶状态，**不再二次确认**。再置顶另一款，两款都应保留置顶，不应把前一款取消。退出页面、重开应用后核对两款的状态与置顶排序仍保留。
3. 长按其中一款已置顶预设，点「取消置顶」，应直接生效；另一款仍保持置顶。
4. 长按测试预设，点「删除」，应继续出现原有「移除预设？」确认，不能直接删除。先点「取消」，核对预设仍在；再重试并确认「移除」，只移除所选项。已登录时，原弹窗会说明本机和当前账号云端预设的移除 / 后续同步范围，按该范围选择测试副本。
5. 用关闭按钮、点击菜单外部或系统返回退出菜单，应不改变置顶或删除状态，只返回原页面一次。菜单打开期间切换账号后，旧菜单不能向新账号执行动作。
