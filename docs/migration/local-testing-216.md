## 瑕疵候选在照片上定位

1. 照片编辑器 →「人像」→「皮肤」→「自动祛痘」。有候选时进入「修复疑似小瑕疵」，应同时看到照片上的编号、修复范围及对应列表；没有候选时应明确提示，不生成修补记录。
2. 默认全选。点照片编号或列表定位项，核对当前查看点相互对应；位置以「塑形前定位」照片为准。已有塑形、裁切或旋转时，也不应把标记放到变形后的错误位置。
3. 逐项取消 / 恢复勾选，核对编号颜色、勾选状态及「已选 N / M 处」同步变化。「全选 / 全不选」应生效；全不选时不可提交修复。仅定位、缩放、勾选或浏览列表不应应用效果。
4. 点「取消」或系统返回，核对进入前的肤色、人脸、塑形及修补均保留，未增加自动祛痘。重新分析后只勾选部分候选，点「修复所选」，应只添加所选完整修复，并作为一次人像撤销；重做应恢复整个批次。
5. 在分析中或确认后的处理中取消 / 返回，确认迟到结果不会回写已退出的页面。账号变化时，旧候选照片应关闭，不能继续确认旧账号结果。

这里的编号是本次照片的候选定位，不代表每一点都需要修复。请在确认前逐项查看；定位照片加载失败时应保留取消入口并停止确认。

## 关闭旁的原版照片菜单

从编辑器左上关闭按钮旁的三点打开锚定菜单，核对原式图标、分组、选中 / 禁用态及窄屏滚动。该菜单是全局照片菜单；人像页原有七项更多操作继续保留。

| 菜单项 | 建议核对 |
| --- | --- |
| 收藏照片 / 取消收藏、直方图 | 收藏状态一致；直方图可切换亮度 / RGB，暗部 / 高光警示只显示在预览中，不写入照片或导出 |
| 照片版本、查看细节 | 版本列表真实可查看；细节页可切换调色前 / 当前效果，使用 100% / 200%、缩放和平移核对实际照片细节 |
| 全部滤镜、快速优化、照片配方 | 能打开相应入口，选择 / 保存 / 应用有效；效果变化可按该功能撤销 |
| 精细构图 | 裁切、拉直、透视入口可用，确认与取消符合原编辑流程 |
| 复制调色、撤销复制 | 先在测试副本之间执行一次复制，再核对撤销；无可撤回记录时应明确说明 |
| 继续编辑 | 仅存在对应草稿时出现并恢复该照片的草稿 |
| 重置调色、还原原图 | 重置调色保留滤镜与人像效果，选区内只重置该选区调色；还原原图清除全部编辑，可撤销 |
| 删除照片 | **仅用专门测试副本**核对确认、取消和删除结果，勿用唯一原片测试 |

菜单内容随照片可读状态、草稿及可删除能力变化，不应把条件隐藏项误判为永久缺失。RAW 未显影时先完成显影，再测「查看细节」。全尺寸细节是只读临时查看，进入、切换和关闭均不应新增照片版本、草稿或系统相册文件；关闭应只返回原编辑器一次。

## iOS 相机连接重点复测

**用户已确认：Nikon Z6II（“Z62”），通过相机 Wi-Fi 连接。实体 iPhone 与相机尚未完成本轮验证，实际停留阶段仍待现场反馈；不能从源码或模拟结果宣称已连接成功。** 以下步骤用于复现并收集明确结果。

1. Z6II 机身进入「连接至智能设备 → Wi-Fi 连接 → 建立 Wi-Fi 连接」，iPhone 在系统 Wi-Fi 设置中连接机身显示的 SSID，再回 Huevia 核对实际 IP / 端口并连接。这也是旧 Android 的引导路径；需要机身确认时查看相机屏幕。保持 Huevia 在前台，并记录 iPhone 型号、iOS 和所装测试包版本。入口依据 [Z6II 官方智能设备连接说明](https://onlinemanual.nikonimglib.com/z7II_z6II/en/09_menu_guide_06_28.html)。
2. 「连接相机」应显示具体阶段及已等待秒数，例如检查 Wi-Fi / 本地网络权限、等待机身确认、建立事件通道与会话、读取存储卡目录。握手完成后，首屏读取应显示独立阶段与「取消读取」，不再统一停留在「正在连接」。
3. 首次连接先完成应用内说明，再在系统本地网络弹窗选择允许。若此前拒绝，可用「打开本地网络权限设置」进入系统设置后重试。系统授权结果仍由 iOS 决定；旧提示取消后立即重试，不应被旧弹窗的迟到按钮结束新连接。
4. 连接握手与初次目录读取共用 **75 秒核心总预算**，到期关闭本次通道并给出停留阶段。首次应用内说明另有 45 秒上限；明确本地网络授权等待最多给 20 秒窗口。页面另有 125 秒连接兜底，首屏读取单独 75 秒；这些是不同阶段的上限，不表示每次都需等满。任一等待阶段都可主动取消。
5. USB 方式用支持数据传输的线和兼容转接器，点「检测 USB 相机」并允许系统访问，再选设备连接。检测 / 授权应可取消；授权等待上限 45 秒，检测页面兜底 50 秒。未发现设备、授权拒绝、会话打不开或系统未提供 PTP 通道时应给出明确错误。
6. 分别在等待授权、机身确认和首屏读取时取消，核对等待结束、可重新尝试，迟到的旧结果不能变成新的已连接状态。系统权限弹窗本身仍需用户作出选择；取消应用操作不等于修改系统权限。

Z6II 的「连接至电脑」属于另一套电脑连接流程，官方说明要求使用 Wireless Transmitter Utility 配对，见 [Z6II 官方电脑 Wi-Fi 连接说明](https://onlinemanual.nikonimglib.com/z7II_z6II/en/10_establishing_wireless_connections_02.html)。目前没有证据认定用户选错了模式，仍需记录现场机身入口和实际停留阶段。

若仍失败，请反馈：**机身所用连接入口、iPhone / iOS、所装版本、最后停留阶段和秒数、完整错误信息，以及是否出现并允许本地网络授权**。若握手已完成但首屏没有照片，请明确是卡在「读取存储卡目录」还是「读取相机照片目录与首屏」，便于区分连接与图库读取问题。
