# 229 相机连接方式与 USB 目录候选修复

用户已选择连接页方案 A（顶部双标签）。所有新建连接默认 Wi-Fi，USB 与 Wi-Fi 在同页切换；已有健康 USB 会话显示真实方式，允许直接返回原功能。同步、相机预设导入、遥控、边拍边传与设置使用同一连接入口。

USB 列表进入有线标签后自动检测。设备卡片只改变选中项，底部按钮显式申请授权并连接；切换标签保留列表及选择。枚举取消只取消自己的 job，不关闭已有照片会话。授权被拒绝时显示错误，用户可重新授权。连接成功直接回到调用功能，连接页不读取照片。

重新连接失败后刷新 Native 实际状态，避免继续展示已关闭的旧会话。Core 在连接前拒绝请求且旧会话仍健康时，保留真实健康会话。刷新有独立超时及 mounted、epoch、statusRevision 守卫。

Android USB 目录区分合法空数组和失败 null；过滤未挂载的逻辑卡槽（storage ID 低 16 位为 0，沿用原版 USB 探测规则）。目录就绪期间最多 3 轮，100/200 ms 退避；JPEG 过滤失败仅首次尝试无格式过滤，最坏 4 次 SDK 查询。每段目录查询 1 秒之后不再启动后续查询；无法强行中断单次系统 MTP 调用。每次查询前后核对当前 Client、MTP 对象、连接、设备在场和线程取消，不重开或关闭传输。照片原文件下载、槽位协议和 Wi-Fi 路由未改。

现有截图只证明 nullable 目录结果被转成了通用错误，无法确认实机究竟在存储枚举还是对象枚举失败，也不能据此确认是否为空卡槽问题。自动化回归不等同于 Z6 II USB 实机通过；需要使用原数据线和相机复测读取、缩略图及 JPEG/NEF 下载。
