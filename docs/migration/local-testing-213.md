# 213 本地测试说明

先安装 [Android ARM64 测试包 213](../../dist/migration213/huevia-0.31.0-dev-213-android-arm64.apk)。新版包名是 `cc.huevia.next`，与原应用 `cc.huevia` 不同，可以同时保留，**不需要卸载旧应用**。

用户已明确“暂不发布，我先测试”：本轮不部署、不上传草稿、不公开发布，新版更新分发接口尚未上线。请从上面的本地附件安装。iOS 仍在修复实际人像检查，暂无本轮已验收 IPA，暂不提供候选包下载。

底部入口为“预设 / 同步 / 相册 / 设置”。以下是可照做的测试步骤，不表示这些项目已经接实体设备验收。

## 原来的 4 项需求

| 项目 | 怎么测试 | 预期结果与条件 |
| --- | --- | --- |
| 多个预设置顶 | “预设 → 我的预设”，分别打开两个本地预设详情，点“置顶预设”；返回列表，再取消其中一个置顶 | 两个都可置顶并优先显示，取消一个不影响另一个。需要至少两个已导入或下载的预设 |
| RAW 曝光与白色高光 | “相册 → 右上更多 → RAW 显影”，选择自己的 NEF；改变“显影曝光”，比较“高光处理”，再点“完成显影，继续编辑” | 曝光变化应可见，白色高光不应凭空偏粉；原 NEF 保留。请用曾出问题的原始 NEF 测试，未知机型仍需实样核对 |
| 注册后立即登录 | “设置 → 顶部账号区域 → 注册账号”，刷新验证码，填写并点“注册并登录” | 成功后提示“注册成功，已登录”，设置页显示账号状态；验证码失败有明确提示，可刷新重试。需要网络和可用账号服务 |
| USB 接收照片 | “设置 → USB 数据线连接 → 检测 USB 相机”，授权并选择相机；打开照片，点“接收原文件” | 显示实际照片和接收进度，完成后在应用相册保留 JPEG / NEF 原文件。需要 Nikon 相机、可传数据的线、手机 OTG / 转接器和相机 PTP/MTP 模式 |

## 本轮 11 类功能

| 类别 | 入口与操作 | 应看到什么 | 需要的设备 / 配置 |
| --- | --- | --- | --- |
| A2 后台与恢复 | “设置 → 后台连接保护”，开启“后台接收保护”；开始接收后切到后台、重开，再试通知中的“停止接收” | 进行中的任务有通知；重开保留进度；通知停止后不继续收片，未完成队列可明确继续 | Android 通知权限；实际接收还需相机。厂商电池策略、锁屏和系统终止仍需手机实测；iOS 仅有限收尾 |
| A3 遥控拍摄 | 连接 Nikon Wi-Fi 后，“同步 → 遥控拍摄”；试“开始取景”“自动对焦”“拍摄一张并保存到相机” | 真实画面和机身参数；支持时可点按对焦。参数只读。结果不确定时先“读取拍摄结果”，不会自动重拍 | 支持该能力的 Nikon、相机 Wi-Fi；不把 USB / 富士连接当作遥控支持 |
| A5 相机槽位 | 连接后打开“相机预设槽位”，选一个可覆盖的 C1–C9；“导入到此槽位”或“覆盖此槽位”，核对预览再确认；也可试复制 / 删除 | 先显示来源和目标，再确认写入；操作后有读回结果。未知结果保留核对入口；活动槽位不能删除 | 支持槽位指令的 Nikon；Wi-Fi 或 USB；兼容 NCP 文件。每次操作后按页面提示重新连接，返回照片页也需重连 |
| A6 多选接收 | 相机照片页点“多选下载”，选两张，点“接收 2 张”；选应用 / 系统相册 / 文件夹目标。也可从“设置 → 相机下载队列”查看 | 逐张进度；停止后“继续未完成项”不重收已完成项；换会话时先核对相机 | 相机；系统相册权限或用户选择的可写文件夹。一次最多 100 张 |
| A7 查看器与 RAW 缩略图 | 相机照片点开后试“上一张 / 下一张”，再“接收原文件”；本地相册查看已有 NEF 缩略图并打开 | 相邻照片切换正确，接收的是当前照片；RAW 列表可显示预览，不需要先生成完整编辑副本 | 相机测试需至少两张照片；本地部分需 NEF。未知 RAW、损坏文件仍应单独试 |
| A8 人像 | 打开照片编辑器的“人像”页，点“人像精修 → 自动选脸与五官分析”或“分析皮肤范围”；调整后试“撤销 / 应用” | 检测到的人脸可选择，调整有可见变化；撤销恢复，应用后回编辑器 | 清晰人物照片。Android 可先测；iOS 实际人像流程仍在修复，不能按已通过处理 |
| A9 自动修补 | 编辑器“人像 → 涂抹自动修补”，在小块目标上涂抹；试“撤销 / 重做 / 应用” | 附近纹理替换涂抹范围；撤销重做可比较，原图仍保留 | 有小杂物或瑕疵的测试照片；不同背景纹理分别观察效果 |
| A10 JPEG / NEF 配对与原件 | “同步 → 相机照片”，打开 JPEG，点“核对并接收对应 RAW”；选择并确认 NEF，再“选择原文件保存位置” | 先核对库存，有歧义需明确选择；NEF 保持原格式，可选“应用相册 / 手机系统相册 / Files / 文件夹”。系统不支持时改选文件夹 | 同次拍摄的 RAW+JPEG、Nikon 和可用存储卡；系统相册权限或文件夹授权。旧 JPEG 不按同名自动猜配对 |
| A11 批量与删除范围 | “相册 → 右上更多 → 选择”，选两张后“批量编辑”；逐张编辑，再“开始批量导出”。另用测试照片试“删除所选照片” | 显示完成数量，可停止 / 继续未完成项；删除前单独选择“应用内原图 / 应用内成品版本 / 系统相册”范围并确认 | 至少两张测试照片；系统副本操作可能要求系统确认或相册权限 |
| A12 QQ 登录 | “设置 → 顶部账号区域 → QQ 快捷登录”，按说明同意并授权；也试取消后返回 | 成功时账号状态更新；取消不误显示登录，也可切换“使用账号密码登录” | 手机 QQ、网络及腾讯登记。Android 登记尚未核实；iOS Universal Link 未配置，真实登录仍待验证 |
| A13 更新与旧资料 | “设置 → 检查更新”查看页面；“设置 → 旧版资料迁入”选择导出 ZIP，先看待迁入清单，再确认 | 本轮更新分发接口未上线，不以下载到 213 为预期。迁入保留已有资料，记录中可“撤回 → 核对并撤回” | 旧资料迁入需下述 194 辅助包；生产部署和公开发布不在本次测试范围 |

## 从旧 Android 带入资料

保留旧应用，在其上覆盖安装同签名的 [旧版资料迁出辅助包 194](../../dist/migration213/huevia-0.30.34-legacy-export-194.apk)，打开“旧版资料迁出”入口，用系统文件选择器保存 ZIP。194 是旧应用的手动安装附件，不是新版 next，也不通过旧更新通道分发。

在新版“设置 → 旧版资料迁入 → 选择资料导出包”选该 ZIP，核对后点“迁入已核对资料”。已有资料保留；需要撤回时在本页的迁入记录点“撤回”。若迁入后又修改了资料，自动撤回会停止并提示，避免覆盖后续修改。旧安装和导出 ZIP 都保留。

如遇问题，记录所在页面、操作顺序及相机 / 手机型号；相机连接页可“导出诊断报告”。当前仍缺实体相机、iPhone 和 16 KiB Android 设备验收，实际通过范围见 [213 总表](remaining-work-213.md)。
