## 本轮八项复测

1. **相册选择留在原网格。** 在应用相册和手机相册各滚动一段后点“选择”，应原地显示勾选状态、已选数量和取消/全选。退出选择不应跳到新列表或丢失原位置。应用相册底部为“编辑、导出、删除”，手机相册为“批量编辑”。先取消一次删除确认，只有专门的测试副本才实际删除；原片、RAW 和版本保护仍保留。
2. **筛选与排序毛玻璃。** 打开预设筛选、相册时间排序，分别在浅色、深色及横屏大字下检查半透明模糊、文字、固定操作条。修改后关闭、点外部或返回，应放弃未应用修改；点“应用”才改变结果。连续关闭/确认不能退出父页面。
3. **预设滚动分页。** 在线预设滑近末端才取下一页，不再点“加载更多”；一次滚动不应持续自动取完所有页，已有预设不重复。断网造成下一页失败后，应保留已加载内容并显示可点的重试；恢复网络后再重试，不自动反复请求。
4. **同步照片按需浏览。** 仅主动进入相机照片后加载目录与首屏；滚动继续浏览，缩略图不应一次全部构建。导入预设的连接成功后返回原导入流程，不自动进入照片列表。
5. **同步工具不换整页流程。** 展开底部相机工具，打开接收队列、遥控或槽位，检查半透明面板、关闭和返回；空接收队列应为较紧凑的半屏工具窗。关闭面板后回到原同步页面；接收队列按已有停止/后台保护规则处理，不因旧面板迟到回调停止新任务。写入/拍摄期间按面板提示操作，不能通过点遮罩绕过确认。
6. **遥控拍摄原式操作。** 检查连接状态、参数格、设置与单次快门；能力不支持时明确提示。设置弹层关闭不应触发额外拍摄；结果未确认时只能核对，不能自动补拍。拍后先只读核对结果，照片接收按用户所选开关执行，不自动补拍。
7. **实时取景。** 主动开启后检查画面、全屏、网格/直方图与返回；设置变更后关闭窗口，旧结果不能重新开启已关闭取景或覆盖新账号。关闭取景应结束相应取景任务并保留可用相机连接，真实故障仍需明确报错。
8. **相机导入九宫格与明确结果。** 从一款测试预设进入“确认导入”，检查预览、C1–C9 三列、覆盖原名提示、兼容适配和可选白平衡/色温/曝光补偿（默认不调整）。先取消确认，应零写入；确需写入再确认一次。只有实际读回核对才显示“已保存到 Cn/已读回核对”；确定拒绝显示导入/删除失败，响应不明显示待核对，不自动重写。预设已保存但拍摄参数未知时应分别说明。浏览槽位时点非空项可选择删除，仍须最终确认，勿用唯一副本试验。

## Z6II Wi-Fi 与连接保持

已确认用户机型为 Nikon Z6II（“Z62”）、使用相机 Wi-Fi。沿用 [219 指南](local-testing-219.md)中的机身入口与连接步骤：机身「连接至智能设备 → Wi-Fi 连接 → 建立 Wi-Fi 连接」，手机连接机身显示的 SSID；iPhone 首次允许本地网络访问。

保持手机亮屏、应用前台，分别在同步页、槽位确认页、遥控未开启取景时停留数分钟，再做只读刷新。系统提示相机 Wi-Fi 无互联网时，记录是否选择继续使用此网络、是否自动切换移动网络；保留原先可工作的网络优化/切网设置，不要同时大改配置。另记录机身待机、屏幕状态、停留时长、具体阶段和完整错误。不要把系统权限弹窗的短暂遮挡当成切后台；真正后台、主动停止和既有接收保护到期仍应按原规则处理。

**这些是复测项目，不是“亮屏 Wi-Fi 已在 Z6II 真机解决”的结论。** 不能用模拟器、假相机或协议测试代替实体相机、iPhone、系统切网与 USB 授权验证。
