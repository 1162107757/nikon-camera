本次六项反馈：

1. 普通停止边拍边传、队列或单张下载不再向正在执行的相机RPC发送会关闭PTP的通用cancel。停止后不再接收新工作，等待当前相机事务完成再收尾；这期间保留busy/job/传输租约。已保存原片与持久记录保留，旧回复不能重新导入/发布或恢复旧任务。明确断开/重连仍可精准取消旧IO，并保护新账号/新session。
2. 未连接时，点击边拍边传标签直接进入连接页，取消后返回Live；中央开始也会先连接，连接成功再显示一次实际开始/继续确认，保留原项目/JPEG-RAW选择，不读取相机照片。取消或账号变化会结束本次开始意图。
3. 按用户 [批准B图二](../design/camera-download-review-20261115/approved-b.png) 使用56dp圆形下载按钮，张数角标，位于原52dp相机工具上方、中心对齐、间隔12dp，避开底部导航。顶部只留已选/全选/取消，不再显示接收按钮；工具展开时让出悬浮位并保留当前选择。
4. 队列传输大小与操作按钮增加20dp间距，按钮至少50dp高；软暂停中显示完成当前传输后暂停。
5. 相机照片长按原地进入选择并选中该张，其他照片点击继续多选，不打开新预览页。
6. 同步三标签保留连续灰胶囊，内边距6dp、项间8dp、48dp触摸区；选中块约220ms平滑移动，支持RTL/大字/系统减少动画，不重挂页面或重载照片。
