# 207：原版导出设置与可重试的相册保存

三个交付包的源码均为 `38594afc49c9deae79e14b46f147bf45d0936225`。原工程、已有安装包及 204–206 冻结记录保留。整体迁移仍未完成，范围以[功能清单](../../feature-parity.md)为准。

## 行为

恢复原 `PhotoVersionExport` 的快捷导出、更多设置、版本选择和成品预览路径。快捷窗口提供轻量、均衡、高清和原画，完整尺寸、分享及自定义使用原导出规格。当前编辑、原图及保存版本各自冻结配方，多选最多 100 个版本。预览完成返回设置，保留选择和自定义数值；预览不提交成品或修改草稿。

实际保存按冻结顺序逐项执行。渲染失败或相册保存失败会停止队列，重试复用同一个成品与保存操作标识，已完成项不再执行。新的明确保存操作使用新的副本标识。源文件身份、账号和参数在异步完成后再次校验；账号变化取消工作并清空旧窗口中的配方和收据。

Android 接入原 `PhotoLiveGallery` / `PhotoEffectGallery`，Android 10 以上添加照片不要求读取相册。iOS 接入 PhotoKit 添加权限与持久保存记录。新 JPEG 副本写入本次导出时间，原图和应用内成品保持原样；重复请求核对相册资源，不能核对的记录保留并报错。Apple 日期写入通过 ImageIO 元数据复制完成，保存前再核对三个日期字段。

原始文件按钮目前仍通过 `source.inspect` 校验私有原图身份后打开系统保存/分享入口。原版 JPEG 的直接相册保存、RAW 的独立格式和目标选择流程尚未完整迁移，不计作本轮完成。
