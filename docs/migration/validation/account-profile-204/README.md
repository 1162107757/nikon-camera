# 204 账号资料、头像与边框缩略图

Android 固定源码 `6d84ab39f8599f2cb209922e8b819916095c6c63`，开发包名 `cc.huevia.next`。原 Android 186 保留并存，整体迁移尚未完成。

恢复原账号资料页、头像选择后的明确复核、上传、恢复默认头像、资料刷新和退出。头像原字节通过两端系统选择器流式进入私有目录，处理为白底方形 JPEG；Flutter 只接收绑定账号及资料版本的复核凭据。账号切换、晚到回调、失败重试、临时文件及图片缓存均隔离。未使用真实账户执行头像上传或恢复，受控传输测试不代替实账号联网验收。

正式包自查复现了四个边框模板缩略图空白：连续请求复用任务标识，而 Android 有时先返回结果、后清理任务，下一张被误判为正在执行。现先清理对应任务再返回，每张缩略图也使用独立标识；旧任务的清理不能删除同名新任务。另修正临时忙碌和无关应用通知后的缩略图恢复，账号切换仍会清除旧内容。
