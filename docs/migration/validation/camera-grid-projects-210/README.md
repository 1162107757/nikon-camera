## 用户反馈与修复

用户确认 209 的 RAW 缩略图已正常，且相机有独立 JPEG，需要与 NEF 分开查看。本轮 JPEG 使用相机按格式的目录查询，遇到不支持或空索引再回退完整枚举；RAW 仍独立筛选，错误与不可用存储卡不再直接等同于零张。

相机照片恢复原版 AlbumPanel 的方形网格、8dp 间距和 14dp 圆角：手机至少三列，宽屏按可用宽度增加。移除文件名、分辨率和大小的详细行，保留格式角标；点击先看相机预览，再明确接收原文件。预览队列在传输时暂停，切换页面不关闭正在传输的操作。

下载展示准备、实际字节、校验、导入和完成状态。进度仅接受当前任务的真实字节，收到原文件后继续核对收据与媒体索引，持久保存后才显示完成。返回网格和切换四个底部标签保留当前相机会话及在途下载；已下载页显示实际保存照片。页面离开与取消下载分开处理。

iOS 使用限定 Wi-Fi 的原生 Network.framework 适配器，修正等待状态下的拒绝连接分类，以及关闭时唤醒并发读取的行为；首次连接前增加本地网络授权用途说明，连接页提供系统设置入口。说明是否展示与操作系统是否授权分别处理。用户已确认旧版在允许本地网络后能连接，本轮仍需实体 iPhone 复测 JPEG、授权首次流程和标签切换。

首页在线库有预设未提供预览 URL，现通过已校验配方与内置样片实际渲染预览。编辑器接通在线/我的预设与分类，在当前照片生成真实缩略图并套用配方，保留不可变编辑历史及所有者隔离。只看预览不自动导入个人库。

## 并行完成范围

三个子任务分别完成并合入：

- 项目预设：复用原项目存储，创建/改名、手动加入 1–100 张已保存 JPEG、不可变默认预设、前台处理队列、取消/重试、已保存成品与重开查看。源 SHA、任务租约和快照身份防止迟到结果覆盖；从预设库移除原配方后项目默认仍可用。相机新片自动入项目、后台服务、RAW 项目和旧项目迁入仍待完成。
- RAW 外部 JPEG 参考：选择/更换/移除、用户确认同次拍摄、源/参考 SHA 和私有相对路径校验、两端原显影色彩匹配与高光安全拒绝。原生综合流程以自身导出 JPEG 验证已接近参考，另用无关棋盘 JPEG 验证拒绝不可靠对齐与保持中性高光；这不代表未知型号 NEF 高光实样已修复或所有非恒等 LUT 都完成实体验收。
- 稳定性诊断：保持 schema 1 兼容，新增 `appStability`；有界保存 Flutter 异常类别，Android 复用原 Java 崩溃/系统退出信息，iOS 接入 NSException 和系统已投递的 MetricKit 汇总。导出不包含异常原文、私人路径或照片内容。无记录不能证明从未崩溃，荣耀 Magic Android 12 仍需实机日志和回归。
