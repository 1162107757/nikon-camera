- Android 预览改为按原 EXIF 方向读取可见区域，避免为整幅旋转 JPEG/PNG 额外建立两份大位图。补入与参照 Android 字体同源的 Roboto，并校验 Android、Flutter/iOS 和 iOS 原生边框的字体字节。
