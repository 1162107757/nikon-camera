# 相册批量导出

在「相册 → App 内」长按一张照片，继续勾选其他照片，然后点底部的「批量导出」。一次最多 100 张；「批量编辑」继续保留为并排的次要操作。手机来源仍使用现有的导入与批量编辑流程。

导出按每张照片各自的状态准备：有待导出的修图草稿时使用该照片的完整草稿，包括滤镜、调色、局部、人像、构图和边框；没有待导出草稿时保留当前所选的原图或已保存效果版本。已经导出的历史草稿不会覆盖用户选中的其他已保存版本。不会把第一张照片的设置复制给整批。

导出设置沿用现有完整尺寸、分享、自定义长边及 JPEG 画质，并逐张显示最终尺寸。可以查看逐张成品预览，选择 App 内或手机相册；现有副本核对与另存新副本规则保持一致。取消设置不清空相册勾选。

设置准备时在后台冻结各照片的原图身份、草稿和账号；确认后冻结规格与目标，后续修改草稿不会改变已确认任务。串行处理，显示逐张进度；部分失败可只重试未完成项。原图不覆盖，后续独立修改的草稿不被旧任务标成已导出。

实现复用 `AlbumPanel.exportLocalWorkspace` 和现有逐张 `PhotoPresetBatch.Edit` 导出流程；本次新增相册选择栏入口和主界面回调，不更改图像渲染算法或草稿格式。
