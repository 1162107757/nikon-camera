# 同步列表操作栏微调

版本：0.28.2-beta（139），本地测试包。

已下载列表的计数显示为“共 x 张”，使用 12sp 常规字重和次要文字颜色。右侧“RAW 原片”和“选择”使用 13sp 常规字重、单行文字和浅暖灰背景，文字颜色与计数一致。进入选择模式后，按钮显示“取消”，保持相同的灰色文字与浅暖灰背景；无障碍说明保留完整的“取消选择照片”。

操作按钮的可见背景高 32dp，上下各留 8dp 的透明点击区域，实际触摸区域至少 48 × 48dp。两个按钮间隔 8dp，圆角与背景高度相配。颜色沿用现有 UiPalette，并适配深色模式。此调整只应用于同步照片列表标题行，没有修改全局按钮样式。

RAW 文件入口、批量选择和取消的行为保持现有功能。相机照片列表共用相同的紧凑操作按钮；已下载计数不重复显示“已下载”标题。

验证记录与截图存放在 `docs/validation/sync-header139/`。独立审阅范围为此次计数、操作按钮与选择状态，不构成整款应用的验收。

最终检查覆盖普通字体、1.3 倍字体、深色模式和 1600 × 2560 / 240dpi 扩展视口，每种配置通过 37 项断言，共 148 次执行（不是 148 个独立场景）。均来自同一台只读 Android 模拟器；大屏是扩展视口模拟，未验证实体平板。模拟器内 APK 与本地安装包的 SHA-256 一致。真实手机与相机验收待设备连接。
