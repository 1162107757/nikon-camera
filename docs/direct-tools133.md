# 直接工具栏（133 / 0.27.1-beta）

132 将完整参数收进“精细调色”，用户反馈入口太深。133 以用户提供的醒图截图为操作层级参考：底部选分类，上面横滑工具，选中参数后直接拖动数值。

- 主分类改为文字与短下划线，直接提供优化、滤镜、人像、调节、裁剪、边框、配方。窄屏和右侧面板可横滑；不会把七个入口挤成小按钮。
- 点“调节”就显示全部 17 个参数与曲线、HSL、调色盘、去灰、局部。亮度、对比度、饱和度、色温排在前面，精细工作区紧随其后。取消“基础 / 更多参数”的切换。
- 参数共用一条数值滑杆与精确输入，已有设置有标记，长按可重置。当前局部选区的名称和作用范围继续显示，局部参数仍独立保存。
- 人像保持自然精修、皮肤、面部、塑形四个直接入口；皮肤、面部的细项仍按原有工作区分组。
- 常用面板统一 204dp（随字体缩放），释放照片空间。撤销、重做、按住原图只保留公共工具行的一组。

保存、账号隔离、草稿格式、选区、识别、算法、模型与导出管线不变。本次只改变三个生产输入：版本定义、PhotoCompactDock、PhotoFilterEditor。

本地验证记录见 `docs/validation/direct-tools133/`。此版本只生成本地安装包，不上传或发布更新。
