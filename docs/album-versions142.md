## 日期整组选取

App 内、手机及同步页现有“已下载”照片的日期标题右侧增加 48dp 点击目标，内部为 22dp 三态标记。浏览时即可点选日期，进入选择模式并选择该日期的全部可选照片。逐张取消后显示部分选择；再次点日期会补齐，整组已选时则清空该组。退出选择会清空选择状态。三个来源共用“今天 / 昨天 / 月日 / 年月日 / 日期未知”文案。相册标题为 14sp，紧凑模式 12sp；同步日期为 14sp。

100 张上限按“已有选择 + 本组”原子检查，超限不截取前 100 张，并提示可逐张选择。手机列表一页最多读取 120 条 JPEG/PNG 元数据；末尾日期可能延续到下一页时，先继续补齐该日期元数据再执行选择，不能把当前页尾误当整组。此过程不导入或解码整库照片。

保留 141 已批准的单条 56dp 悬浮操作栏，外圆角 28dp、最大宽度 420dp、左右 16dp、系统安全区内底部另留 14dp。各动作至少 48dp，数量只在栏内显示；手机为“取消 / 已选 x 张 / 批量编辑”，App 内为“取消 / 已选 x 张 / 保存 / 编辑”。选择与准备期间来源锁定，隐藏顶部总量行、更多及根导航；照片列数、尺寸与原有对齐不变，列表末尾保留避让。取消、系统返回及准备请求失效规则沿用 141；保存设置取消保留所选照片。

手机权限、部分授权标记和选图边界沿用 141：进入手机页不自动申请权限，已授权浏览无常驻选图按钮，未授权空状态保留授权与指定照片入口。142 的新功能未另行完成权限撤销变体验收。

## 已保存版本与当前编辑

多版本照片的卡片及预览显示实际当前已保存版本名。相同预设名在当前标签和导出选项中增加序号，避免只凭同名判断版本。选择版本会持久记住该显示文件。

打开照片现在显示所选已保存版本；其他未导出草稿继续保留，通过现有“继续编辑”或恢复草稿操作明确恢复。切回已保存版本展示其真实像素，不自动套用其他待处理草稿。只在完整匹配时恢复已导出版本参数的保护不变。

单张多版本照片在同一原生保存弹层内显示版本名、缩略图和多选框，默认仅选中当前所选已保存版本。存在明确的当前未导出编辑时，它以独立“当前编辑”项出现并默认选中，使用可见编辑状态冻结的预设、调节、构图、边框、局部参数及账号。已保存版本使用各自文件与冻结哈希，不能隐式替换为当前编辑或另一份草稿。只有一个已保存版本且没有当前编辑时，不增加额外版本选择器。

批量保存默认每张照片各自的当前已保存文件；“导出全部版本”为主动勾选。如果展开后超过 100 个输出，该项禁用并说明总数与上限。每次弹层使用准备时的目录快照。原图全尺寸 Q95 导出可能沿用既有渲染流程生成中性输出，并成为另一已保存版本；所以下次“全部版本”按最新目录重新计算，不保证版本数量固定。

129 及其在 141 中延续的“自动使用每张照片待导出草稿”说法由上述明确版本选择取代；原始文档与验证记录按历史保留，本次有效安装包以 142 为准。141 的悬浮栏几何、来源、返回与权限规则继续有效。

## 保存弹层与实际输出

沿用暖石墨弹层与蜜桃勾选。每个版本行至少 56dp，复选框目标 48dp，缩略图 40dp，名称 13sp，辅助文字 12sp，“当前”标记 11sp。长名称单行省略，完整名称保留在无障碍描述或提示中。画质标题使用 13sp、固定 52dp 宽，右侧 Spinner 按剩余宽度分配，避免窄屏标题换行。紧凑高度纵向滚动；三版本初始视口下主保存按钮位于首屏下方。

选项、名称与冻结参数会进入真实 `PhotoPresetBatch.Edit`，经过快捷保存、详细设置及返回、尺寸/画质选择、目标选择、队列发布与失败重试。快捷保存明确请求手机新副本；详细设置保留 App 内保存、已有副本复用与另存副本控制。已保存效果的全尺寸输出使用其实际保存像素；普通原图走既有 Q95 渲染，不借用另一版本的参数。

版本文件名由原名与清理后的版本名组成；同一请求内重复名称增加后缀。文件名随设置、目标、进度项、实际发布和重试携带。既有 MediaStore 唯一收据、冻结暂存、内容和所有权检查继续避免覆盖旧副本；已成功发布后的重试复用同一请求。原图、旧公开副本及停放草稿继续保留。

主要实现依据：

- `app/src/main/java/cc/huevia/ui/LocalAlbumPanel.java`：日期选择、手机分页补齐、版本卡片及选择。
- `app/src/main/java/cc/huevia/ui/AlbumPanel.java`：同步已下载分组选择、版本标签和共享批量保存入口。
