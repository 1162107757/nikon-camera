# VitalityFilm_Pmango comparison, build 165

The supplied 392-byte NP3 is unchanged (SHA-256 `448299b52677b06a6df831e06c028f43caf8da71b5b5039f1bc8cf9ca56e01ea`). It was imported into installed Nikon NX Studio **1.11.0**, applied to a working copy of the same Nikon Z6 NEF, and visually inspected. No personal JPEG was adjusted.

Reference RAW: `.tooling/raw-native/samples/nikon-z6-lossless-14bit.NEF`, 30,164,134 bytes, SHA-256 `c079345fc93f53a4f0d322f8ddaae505f920c36015f25b58befccaa61db1af31`. Its existing `SAMPLE.json` records raw.pixls.us / CC0-1.0 provenance. Working copies and full 16-bit TIFFs stay in ignored `.tooling/np3-vitality165`; the user-provided preset is not embedded in shipped assets.

NX exports used Latest Picture Control, the unchanged original WB (3044 K / -0.74), zero exposure compensation, Nikon sRGB and 6048 × 4024 uncompressed 16-bit TIFF. The four exports are neutral Flexible Color, the original preset, original preset with the entire Color Grading section neutralized, and a neutral preset with only the original three grading brightness values / blending retained. Names of the two generated research copies start with `HV165_`; they are not replacements for the user's file.

The original parameters read by Huevia agree with NX controls: sharpening 3.50, mid-range 1.50, clarity -1.00, contrast -4, highlights +54, shadows -17 and blacks -3. The old common `brightness / 200` RGB lift in Color Grading was much stronger than the isolated NX brightness control. Build 165 uses a conservative `brightness / 1600` lift. Color Blender brightness, hue, saturation, spatial settings, stored parameters and camera-transfer bytes keep their existing behavior. Flexible Color model identity advances to `...spatial-v4`, invalidating old generated previews; monochrome identities remain unchanged.

The six PNGs are 900 × 599 derivatives for repeatable comparison. The standalone Java utility applies the app's **point-colour** profile to the neutral PNG; the reference comes from NX processing the same RAW. A 2-pixel Gaussian blur limits spatial/sharpening differences in this narrow measure. Mean absolute encoded-RGB difference falls from **29.106** to **8.351**. The isolated brightness control separately falls from 23.953 to 3.806. These are local RGB regression measurements, **not perceptual Delta E, full spatial validation, multiple-photo calibration, or pixel equivalence with Nikon's proprietary RAW engine**. Remaining base-render / HSL / tone-zone differences are visible in the comparison.

Recompute with `python tests/measure-np3-reference.py docs/validation/np3-vitality165`. Re-render with `tests/np3-java/cc/huevia/ncp/Np3ReferenceRender.java`, passing the external user NP3, neutral PNG and destination PNG. The full user preset is the held-out combination after the isolated brightness observation; there is no filename or hash special case in the app.

Official operation references: [Flexible Color controls](https://nikonimglib.com/nxstdo/onlinehelp/en/the_picture_controls_flexible_color_23.html), [importing custom Picture Controls](https://nikonimglib.com/nxstdo/onlinehelp/en/copy_custom_picture_controls_50.html).
