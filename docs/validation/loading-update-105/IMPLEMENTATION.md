# 105 / 0.21.6-beta — 加载、系统选网与更新界面

本轮基于冻结的 104，仅交付本地安装包。线上 mandatory 100、发布记录和后台契约未改动。

## 用户可见变化

- 在线预设首次加载显示与照片卡片对应的动态占位图，标题旁保留简短“加载中”。列表已有内容时继续显示原列表。动画随视图离开页面停止，系统关闭动画时显示静态占位。
- 手机未连接 Wi-Fi 时，点击连接直接打开系统 Wi-Fi 选网；返回后沿用实际网络确认与相机连接流程。移除手动名称、密码和隐藏网络入口，保留取消与重新选择作为系统选网未完成时的恢复操作。手机已经连接 Wi-Fi 时沿用原有复用逻辑。
- 更新页用当前版本/通道行、版本状态卡、单个主操作和更新内容区域重新组织；下载使用实际进度，校验和安装分阶段显示。自动更新弹窗同步调整信息层级和按钮样式。提示尽量简短。

## 变更边界

生产输入 214 → 215，仅 `app/build.gradle`、`MainActivity.java`、`UpdatePanel.java` 和新增 `CatalogLoadingView.java` 有变化。`AppUpdateManager`、`UpdatePolicy`、相机协议、传输实现均保持 104 输入。

普通/强制更新的跳过限制、退出和重新检查、任务协调、下载取消规则、包名/版本/哈希/签名校验、安装前确认、未知来源安装权限和提示去重沿用已有实现。没有加入虚构进度或自动安装。

## 验证

策略主机测试 66 项、更新管理器主机测试 37 项、真实 Wi-Fi 会话运行时测试 29 项通过。组件原生测试覆盖浅色、深色、1.0/1.3/2.0 字体倍率和关闭动画；检查动画像素变化、离开视图后停止、版本卡各阶段、普通和强制弹窗、长说明滚动与按钮可见性。

真实 MainActivity 原生探针检查系统选网 Intent 自动发起、无手动输入、取消仅处理一次和等待清理，并验证主页面确实挂载动态加载视图、实际更新路由可以显示。系统设置启动被测试监视器拦截；未在手机连接真实相机热点，也未执行真实下载、安装或发布。截图中的 99.0.1-beta 是组件测试专用版本，不是发布版本。
