## 功能与边界

照片「调节」增加同级调色盘入口。二维拖动改变颜色浓淡／影调对比，独立强度，支持精确输入、撤销重做、重置、按住对比和全图／涂抹区域。参数独立保存，保留旧手动滑杆。新草稿 PED7、配方 PRC4、局部 v4 按需启用；默认旧数据格式不变。暖色保护采用色相启发式，不声称复刻 vivo 或 Apple 私有成像算法。

用户随后要求增加滑动特效。最终候选加入面板轻柔滑入、白点按压回收、重置／撤销平滑移动；真实拖动即时跟手，可打断动画，系统关闭动画时使用静态反馈。没有对照片做装饰性的模糊或淡入。
