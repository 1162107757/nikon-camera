# 97 遥控工具的未选中状态

Operate 模式，局部保留现有布局、图标、齿轮收纳和保存语义。用户反馈九宫格发灰，像无法点击，但实际可用。原因是 View 对未选中网格及收起直方图应用 0.55 alpha，把切换关闭画成禁用。

可用工具统一保持完整亮度：未选中为现有 TEXT 白色，选中为现有 ACCENT 桃色。确实不可用的对焦、快门、最近照片状态不变。Android 30+ stateDescription 明确网格开启／未开启、直方图显示／收起，不改变固定操作名称或点击行为。

用户追加检查边拍边传速度。本轮增加 AlbumController 的队列调度优化：成功预览不再额外等待 250 ms，已就绪的下一次事务立即排队，并让新照片事件及时唤醒；仍通过原单线程执行器逐个执行 PTP 事务，相机忙碌、描述符未就绪、失败重试、队列顺序及 3 秒漏事件补偿轮询不变。遥控拍摄的“拍后传入”走另一条 downloadPhoto 路径，没有这两处固定等待，本次不把队列收益归到该路径。未更改 socket 参数、JPEG 校验、落盘校验、相机命令或图像质量。

生产修改 RemoteCaptureView、AlbumController 和版本信息。97 原生验证仅做工具栏状态、点击及完整画面不变的定向冒烟，不重复 96 已通过的快门／下载全套测试，不发送快门。四种配置采集 ready、grid-on、grid-off、histogram-off；使用自有隐藏只读 Pixel_9 模拟器与原内存 PTP/IP 夹具。当前相机画面／读数仍是模拟证据，不能据此宣称用户实机恢复。

传输优化另做完整相册主机回归及同夹具前后比较。8 张各 1 MiB 的合成 JPEG，通过生产控制器和 PTP/IP 解帧、预览、原图私有保存链路，改前 4346 ms，改后 420 ms；每张仅一次原图下载，完整字节及预览先行保持。内存传输夹具不包含无线链路、相机写卡、手机存储性能或系统相册发布，耗时仅说明 App 固定排队等待消除，不能换算为实机 MB/s 或相机提速倍数。原始输出为 throughput-before.txt／throughput-after.txt。

用户关于 AF-S 的问题：AF-S 为单次自动对焦，和单张快门释放是独立设置；本轮不改相机参数映射或设置。依据：[尼康 Z6II 官方手册 Focus](https://onlinemanual.nikonimglib.com/z7II_z6II/en/05_basic_settings_01.html)。

原生不运行 HTML/CSS detector。收尾只按本次状态识别问题审核，不进行重设计或全 App 再认证。保留 94／95／96 安装包；不操作实体设备、不上传发布。
