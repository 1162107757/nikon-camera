# 管理端 APK 上传上限扩容至 100 MiB

日期：2026-11-13。唯一工作目录：`D:/dev/ai-project/nikon-camera`。

## 结果

生产管理端、服务端校验、数据库和 COS 路径、下载页面、备份读取和恢复脚本已支持 100 MiB（104,857,600 字节）。刷新管理页面即可使用，无需更新用户 App。

- 512 KiB 分块保持，最大 200 块，编号 0–199；超出 100 MiB 或编号 200 被拒绝。
- 每日声明额度 400 MiB，实际写入额度 800 MiB，延续约四份满大小包的容量。分块和最终对象双计，不清零历史计数。
- 保留每 15 分钟 256 次变更请求、4 个上传任务及管理员权限。公开下载仍按 IP 隔离，其每小时次数、流量签发预算与重试规则保持。
- 保留包名和签名证书约束、v2/v3 完整性校验、草稿/上架/撤回与强制更新策略。APK 解压体积仍受 512 MiB 上限约束。
- 合并改为单个目标缓冲区，逐块验证后写入；完成校验串行执行，等待请求取消时不接管上传。重复大对象改为流式校验，避免额外读取整包副本。
