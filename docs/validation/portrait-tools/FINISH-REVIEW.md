## 2. Behavior & implementation

五项功能均通过不可变人像模型接入同一处理链。多人设置独立，手动笔触和祛痘源位置可序列化，旧版局部编辑数据兼容。蒙版叠层和完整输出共用蒙版计算；人像坐标归一化在 EXIF 朝向后的原图上，处理先于构图与边框。

取消仅关闭暂存对话框；应用回调校验 generation、owner、request 和起始编辑快照，在主编辑器中只增加一次历史记录。独立分析副本排在辅助任务之后回收，借用初始图像由宿主在 dismiss 后释放，过期预览有丢弃和回收路径。

最终报告验证了：取消不写编辑器或草稿、一次应用一次主撤销、草稿恢复、照片隔离、模拟账号不匹配拒绝提交、空白识别真实空态和手动恢复。两张完整参考与实际细节输出各比较 524,288 像素，独立 EXIF6 比较同样为 524,288 像素，三项均 `differentPixels=0`；细节瓦片抽样 1,922 点，`pixelErrors=0`。
