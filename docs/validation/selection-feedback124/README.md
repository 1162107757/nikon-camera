# 手动选区反馈 · 124

版本 124 / 0.24.2-beta 只调整 `PhotoBrushDialog` 的显示反馈。相对已封存的 123，生产输入仅此文件和版本号变化；预设解析、人像/皮肤处理、选区几何、参数和导出实现保持不变。

## 行为

- 有效涂抹或擦除松手、重开已有选区、撤销和重做后，显示“强暖白 220ms → 原淡色 140ms → 强暖白 220ms → 原淡色”。空选区不闪。
- 原软蒙版仍为暖白 `#fff1e4`、最大 alpha 38。强阶段用独立 Paint 的 alpha 色彩矩阵将显示峰值提升到 104，不改缓存像素、覆盖权重或路径，也不增加 mask 位图。
- 选中反馈与完成流程分离；新笔触、擦除模式、大小/羽化、双指、清空和关闭立即取消反馈，不锁触摸。
- 完成仍闪两次后提交并关闭，中间保持干净原图；参数调节页没有常驻蒙版。
- 系统关闭动画时，简化为一次 220ms 强调。

## 验证范围

专用 reflection-only 原生探针使用内存合成渐变图，直接打开真实 `PhotoBrushDialog`，捕获真实 Canvas 四阶段。核对强度提升、原淡色逐像素恢复、范围外不变、原图/蒙版/设置/历史不被动画改变，以及连续手势、重开、完成、关闭和系统关闭动画的行为。

仅进行手机一批与大字号、横屏的短确认，没有重复与此显示变更无关的 NCP149、17 项参数或模型推理矩阵。既有大范围验证见 [123](../ncp-preview123/VALIDATION-RESULT.json) 和 [122](../brush122/VALIDATION-RESULT.json)。本轮具体结果与清理记录见 `NATIVE-SUMMARY.json`。
