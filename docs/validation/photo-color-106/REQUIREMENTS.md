# 曲线、HSL 与批量复制调整（106）

用户在核对待办后批准“开始处理”，本轮落实建议中的曲线、HSL 和批量复制调整。模式：Operate。继承现有编辑器的照片优先布局、暖黑工具区、系统字体和杏色操作，不改首页或其他编辑工具的视觉系统。

## 界面与行为

- 在“调节”参数行增加曲线和 HSL，同一功能也可从更多菜单进入。复杂调色在专注工作区操作，保留当前照片，取消/系统返回不写入；应用后只增加一步撤销。预览失败可重试，未完成当前预览前不能应用。
- 曲线提供 RGB 总曲线及红/绿/蓝独立通道。点击添加、拖动移动；每通道最多12点，输入0–255且严格递增，端点输入固定。提供上一点、下一点、添加、删除及精确输入，单通道和全部曲线分别重置。
- HSL 提供红、橙、黄、绿、青、蓝、紫、洋红8个连续衔接的颜色范围。每组色相、饱和度、明亮度为−100至100；色相内部上限±30度。滑杆和精确输入共用校验，可重置当前颜色或全部 HSL。
- 更多菜单“复制调整到其他照片”：从当前相册组选择已下载照片，再选择基础调节、曲线、HSL的覆盖范围，默认三项都选。只保存草稿，保留各图滤镜/强度、构图和边框，原图不改。选择零项/零张或超过100张不能提交，同一原图的重复版本只处理一次。
- 完成提示提供撤销；更多菜单保留“撤销上次批量复制”。撤销逐张比较本次结果，只恢复仍与复制结果一致的草稿，保留后来编辑过的照片。撤销记录限本进程当前账号，不承诺跨进程恢复。

## 处理与兼容

已有滤镜/强度 → 手动曝光和相对冷暖/明暗/饱和度 → RGB总曲线 → 单色通道曲线 → 分色HSL → 现有空间细节处理 → 构图 → 边框。曲线使用形状保持三次插值；HSL在编码sRGB域使用相邻色区平滑衔接，灰度保持。它们属于手机后期处理，不声称 Nikon/NX 等效。

预览、完整尺寸私有JPEG渲染、草稿、我的配方、撤销/重做和导出身份共用不可变模型。中性曲线/HSL保持旧效果身份。新草稿PED5兼容读取PED1–4，新配方PRC2兼容PRC1；未知版本/损坏数据明确失败，不静默丢弃。

批量复制先准备全部目标，按前一份完整草稿比较后写入；冲突或账号/任务变化中止并尝试恢复此前写入，不覆盖并发新编辑。撤销同样检查账号和目标状态。未新增 RAW 显影、蒙版、降噪、颗粒或跨进程队列。

保存版本能找到原图，但无法恢复该版本对应的滤镜/构图/边框参数时，整批在写入前停止并提示改选原图，不能用中性草稿代替。已存在的可恢复未导出草稿继续沿用编辑器的正常恢复规则。

## 验证与完成标准

主机检查：曲线中性和插值边界、分色选择性与衔接、透明度/源像素保护、预览和完整像素模型一致、旧草稿/配方迁移、新值持久化与身份、复制范围、保留几何/边框/滤镜、冲突/取消恢复及撤销保护。

原生检查：真实MainActivity/AlbumPanel/PhotoFilterEditor及其新增工作区，实际JPEG、草稿、配方和私有完整尺寸导出。矩阵为竖屏1.0、竖屏实际字号1.3、横屏1.0；批量复制和取消/撤销均通过真实绑定按钮。检查截图文字、操作区域与照片空间。原图哈希保持，测试夹具和测试包清理后退出自有模拟器。

质量基准：承接现有裁剪工作区的原生操作，所有关键命中区域至少48dp；不在照片上增添说明卡、占位百分比或浮夸动效。原生平台不运行Web设计检测器。完成前按Impeccable工作流提交独立截图复核与限定记录；测试不代表实体手机性能或相机/NX颜色认证。
