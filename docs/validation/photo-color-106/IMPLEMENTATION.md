# 106 / 0.21.7-beta — 曲线、HSL 与批量复制调整

本轮落实用户批准的三项后续功能，本地候选包见 `dist/huevia-0.21.7-beta-debug.apk`。界面继续沿用照片优先的暖黑编辑器，复杂调色进入单独工作区。具体行为、处理顺序和质量基准见 [REQUIREMENTS.md](REQUIREMENTS.md)。

## 使用

- 打开已下载照片，在“调节”参数行选择曲线或HSL；更多菜单也保留入口。曲线支持RGB总通道与红/绿/蓝、添加/拖动/删除点、精确输入和重置。HSL按8个颜色范围调整色相、饱和度与明亮度，支持滑杆、精确输入和重置。
- 工作区内修改仅用于预览；取消/系统返回不写草稿，应用只记一步撤销。预览失败可点击短提示重试，当前预览未完成时应用按钮暂不可用。
- 更多菜单“复制调整到其他照片”，先选择同组照片，再选择基础调节/曲线/HSL。覆盖所选调节项，保留目标滤镜/强度、构图、边框；只更新草稿。提示或更多菜单可撤销本次复制，已被后续修改的照片保留新设置。撤销记录限本进程当前账号。

## 模型与保存

`PhotoCurves`保存每通道2–12个点，采用形状保持三次插值及256项查找表，插值输入和输出为编码sRGB。`PhotoHsl`采用8个相邻色区平滑衔接，灰度保持。它们并入不可变`PhotoAdjustments`，基础调节不会清空高级项。预览、完整像素渲染、撤销、草稿与配方共用模型。

仅对非中性的高级调色采用固定长度SHA-256渲染模型身份，覆盖基底/滤镜强度/所有调色值；保持旧基础调节的中性及模型身份，复杂曲线组合也能进入现有模型记录长度范围。草稿PED5兼容PED1–4、配方PRC2兼容PRC1。批量复制和撤销在同一草稿锁内比较完整前态，包含像素相同但控制点结构不同的中性曲线；冲突或账号变化不覆盖更新的草稿。
