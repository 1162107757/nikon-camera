## 实现

- 应用相册长按／选择后，浮动栏可删除照片。确认范围包含选中照片的应用内全部版本及别名；手机相册和相机原图保留。实际文件操作沿用既有私有副本删除器，删除前重新核对组成员，遇到占用或版本变化先停止。成功刷新共享相册与缩略图；删除中禁用取消，系统返回不丢失后台任务的结果通知。
- RAW 的 95% 对应像素计算后保存工作 PNG，旧 Android PNG 编码是主要耗时。新有界无损 RGB PNG 写入器采用 Sub 过滤及快速 zlib，同时计算 SHA-256；保存进度来自实际行处理，95–99% 显示“保存中”。取消、I/O 异常、源文件变化和原子提交检查保留。
- 已验证 JPEG 编辑副本先按源文件、设置身份与 JPEG 哈希复用，避免每次重入都先读取完整工作 PNG。仍保留源文件、检查回执及源文件身份，不降低分辨率或调整显影参数。LibRaw 和色彩还原算法未改。
