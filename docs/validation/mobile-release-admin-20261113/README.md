# 双平台版本后台与 IPA 下载（2026-11-13）

已上线后台版本管理与下载页功能；本轮没有上传或上架任何客户端测试包。

## 使用方式

- 后台 App 版本分为 **Android 新版 / iOS / Android 原版**，三个列表与上传通道独立。
- Android 上传已签名 APK；服务端读取版本、包名并校验既有签名。原版上限保留 100 MiB，新版上限 128 MiB。
- iOS 上传未签名 iPhoneOS ARM64 IPA，上限 128 MiB。服务端校验包结构，读取应用标识、构建号、版本和最低系统要求。
- 填写更新说明、选择正式版或测试版，上传后先生成草稿。复核版本和 SHA-256 后确认上架，才能被公开下载；撤回会停止新的文件下载，不自动回退旧版本。
- iOS 下载页直接下载 `.ipa` 文件，并标明由用户自行签名后安装。没有自动安装、企业分发或 `itms-services` 入口。
- 下载页可切换平台、Android 原版／新版和正式版／测试版；二维码与分享链接保留选择。iPhone/iPad 常规移动 UA 默认选择 iOS，未指定平台的原有 Android 链接仍使用原版通道。
- 当前 iOS 和 Android 新版各自尚无已发布版本，页面显示未发布状态。管理员上传并确认上架后，才会出现真实文件下载按钮。

后台：[App 版本](https://admin.huevia.cc/preset-library/admin/#releases)。
下载页：[iOS](https://huevia.cc/preset-library/download/?platform=ios)、[Android 新版](https://huevia.cc/preset-library/download/?platform=android&edition=next)。
