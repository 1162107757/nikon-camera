# 104 / 0.21.5-beta：连接阶段与设置收纳

## 用户范围

用户在建议列表后要求开始；按明确推荐的优先项1、2实施：连接分步提示，以及将IP、端口和长说明收纳到连接设置。照片页遥控入口、预览／原图标识、其他成功反馈暂未扩大改造。

## 实现

- 默认连接页保留品牌选择、连接按钮与“连接设置”。连接时在原按钮位置显示当前阶段及取消入口。仅用当前阶段文字，不提供虚构百分比或计时进度。
- Wi-Fi准备由现有宿主入口处理；实际开始相机连接后显示“连接相机”。富士从真实`cameraState`授权等待进入“请在相机按 OK”，确认后继续初始化并显示“读取照片”；相机已授权时不要求多按一次OK。
- `PhotoCameraClient`增加可选的只读阶段观察接口；`AlbumController.ConnectionCallback`将阶段投递到主线程。控制器generation及界面epoch／connectionIntent阻断取消或切换后的旧阶段。连接结束（含失败）清空客户端观察者，避免活动会话保留Activity回调。
- 相机握手、原有确认等待与重试边界、三个端口、模式协商、网关规则均保持。观察者异常不会破坏握手；不得代替用户确认或发送额外相机命令。
- 设置展开后先显示IP、端口及自动地址开关，长连接说明在后面。折叠不丢输入；自动网关模式下IP保持只读；品牌切换仍读取各自保存配置。输入校验失败自动展开设置。滚动区为浮动导航留出像素高度。
- 错误以“连接未完成 · 详情”或“确认超时 · 详情”显示，点击保留完整原因。补修Wi-Fi准备阶段失败时原始错误被通用摘要替换的问题。删除重复的连接开始全局提示；已连接的富士提示简短确认JPEG能力，实验范围说明保留在设置内。
