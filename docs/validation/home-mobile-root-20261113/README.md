# 原官网首页双平台下载入口修正 · 2026-11-13

正式入口为 **[https://huevia.cc/?channel=beta](https://huevia.cc/?channel=beta)**。此前的双平台后台上线没有同步独立托管的根首页，本轮补齐原首页并统一下载链接。

## 实现

- 保留原首页的摄影素材、首屏、工作流介绍与整体样式，仅在原下载区增加 Android／iOS 和 Android 原版／新版选择。
- 首屏“下载 iOS 版”启用，点击后切换同一首页内的下载区。正式版／测试版切换、平台选择与二维码均保留当前渠道，浏览器仍处于根路径 `/`。
- iOS 已发布版本直接提供 IPA 文件下载，并说明用户自行签名安装；未上架时明确提示未发布。当前没有 iOS 或 Android 新版已上架文件。
- 对三个下载通道分别校验身份、大小、哈希与固定文件路由；快速切换时旧请求不能覆盖新平台结果。
- 后台“打开下载页”、兼容下载页的分享二维码及文件错误页返回链接，统一使用根首页。Android／iOS 文件 API 的既有路径保持。

## 部署与保护

轻量服务器 `lhins-ohyn9xlu` 的静态站点仅变更 `index.html`、`home.js`、`home.css`。先核对线上 HTTP 与仓库基线，再在服务器上验证旧目录及三个文件摘要，复制到新版本目录并原子切换 `current` 符号链接。

- 旧目录：`/var/www/huevia-home/releases/20261108-download-13140639`。
- 新目录：`/var/www/huevia-home/releases/20261113-mobile-488717ad3a33`。
- 其他 13 个文件逐个比较内容与权限，全部相同；Caddy 两份配置摘要相同，服务保持 active，没有重启或重载 Caddy。
- 主云函数基于刚上线的 53 文件包仅替换 4 个相关文件；部署后所有文件内容与 Unix 模式和候选完全一致，运行时配置保持一致。
- 本轮不改数据库、存储权限、备份服务、客户端包、更新策略或已发布版本。
