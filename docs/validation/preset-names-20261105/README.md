# 390 款在线预设名称中文化

2026-11-05 11:45（北京时间）完成生产目录更新及公开接口核对，全部 390 款保持上架。NCP 154 款，NP3 236 款，无缺漏、重名或仅含英文的目标名称。完整对照见 names.csv；后台效果见 admin-chinese-names.png。

## 命名规则

- 原名称能表达风格时按语义译为中文，例如 BlueHour → 蓝调时刻、milk → 奶油低反差。
- 品牌信息保留并中文化：尼康、佳能、富士、柯达、徕卡、宾得、阿莱、爱克发、柯尼卡等。机型、胶片识别码和必要的系列编号保留。
- 难懂缩写结合实际配方命名。例如 nl_s0～9 的变化是锐化而非饱和度，对应“中性线性·锐化0～9”；st_ln_s2 的饱和度为 +2，对应“标准线性·饱和+2”；Mono-no_eff-serp1/4/7 为棕褐调色的不同浓度。
- 相同系列保留版本区分，不能仅将不同文件统一为一个中文名。作者、来源、原始文件名与旧名称继续保留在既有说明、原文件和历史记录中。名称不是相机兼容性或官方效果还原的声明。

## 变更与核对

先备份 390 条完整预设记录、631 份历史版本及公开目录，再取得全部配方文件，逐个校验 SHA、长度与 NCP/NP3 容器。原始备份和按版本核对的回退 SQL 保存在 Git 忽略的 online-library/.local/preset-names-20261105。

生产函数的整批演练在子事务内执行保存和发布，随后回滚。演练后的完整数据行与全部历史版本逐项一致，见 dry-run.json。正式操作沿用既有保存/发布事务，检查预设 ID、版本、当前名称、配方 SHA、草稿与上架状态；若发生并发冲突，整批事务回滚。

正式更新仅改变 draft/published 的 name，并正常增加 390 个历史版本及更新时间。ID、原文件名、配方 SHA、长度、格式、样片、说明、分类、排序和原上架时间逐项一致，旧的 631 份历史快照完整保留。公开目录与原始目录的差异严格仅限于这 390 个 name 字段，条目顺序保持一致。见 name-verification.json 和 FINAL-STATUS.json。

后台刷新后已实际显示中文。由于管理页按“最近更新”排序，其页面顺序可变化；公开目录与信息流使用的原排序、上架时间没有变化。

## 生效范围

这次直接更新在线目录及读取该目录的在线内容，不需要重新发布 App。手机已经下载的条目使用独立的本地名称；现有 App 会保留这些名称，也保留用户自行命名的内容，本次没有迁移本地条目。未更改、构建或上传 Android App，也未改动另一个任务正在实施的功能。

可复用的名称对照是 online-library/data/preset-names.zh-CN.tsv，操作工具为 online-library/scripts/rename-preset-names.mjs。它是显式执行的维护工具，不在目录读取时自动重命名未知的新预设。回退 SQL 已生成但没有执行。
