# 99 · 自动提示与强制更新

2026-10-25。用户要求：“有新版本弹出更新提示，更新要可以设置强制更新”。沿用现有更新页、可信下载与系统安装流程，不新建一套分发体系。

普通更新显示版本、体积和更新说明，可立即更新或稍后；同一制品提示后8小时内不重复弹出。启动及回到前台后自动检查，成功30分钟、失败1分钟节流；前台定期检查空闲状态。未明确选择通道时，测试安装包查询beta、正式版查询stable；显式选择保持。

管理员可按版本设置普通／强制、解除强制或撤回。强制更新没有跳过入口，Back和点外部不能关闭；可以重查策略或退出应用。下载／校验／安装失败保留重试入口，用户取消系统安装不会解除要求；服务器成功取消强制、撤回或实际安装达到目标才解除。正在传输、拍摄接收或导入时等待安全时点；安装前保留既有相机任务与断开确认。

安装必须经Android系统授权及确认，不能静默安装。旧客户端不能被远程补上强制逻辑；本轮99及后续客户端支持新字段。此轮没有给任何线上版本开启强制，也未上架新APK；后台需先部署014迁移及对应服务／管理页后，在线开关才可使用。
