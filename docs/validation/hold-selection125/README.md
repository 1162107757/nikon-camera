# 实时涂抹与按住查看选区 · 125

125 / 0.24.3-beta 延续 124 的暖白色提示，将划动过程本身加强，并加入临时查看按钮。

- `PhotoBrushDialog` 在 DOWN/MOVE 时立即显示强暖白蒙版，覆盖实时补选与擦除结果。松手后两次提示结束即隐藏。
- 涂抹页右侧的选区按钮为按住操作：按下显示全部当前范围，松开、移出、多指取消、失焦或关闭即隐藏。无障碍轻点提供有时限的查看，不变成开关。
- 参数工作区的同一操作仅在选中涂抹区域时出现，位于画面右下、原图比较按钮左侧。展示副本与现有照片使用相同预览尺寸和变换，释放后恢复真实预览。
- 当前照片、选择路径、参数、草稿、撤销、完整导出和细节处理保持原有数据流程。临时蒙版不进入处理配方。

本轮限定验证实时显示、按住/释放、取消和失焦、快速重按的异步归属，以及旋转/裁剪/边框后的范围位置与缩放移动保持。测试仅使用合成图片，不访问用户照片或相机。不重复 NCP149 或完整人像矩阵；原有处理验证见 [124](../selection-feedback124/VALIDATION-RESULT.json)、[123](../ncp-preview123/VALIDATION-RESULT.json) 与 [122](../brush122/VALIDATION-RESULT.json)。

最终包、冻结来源及原生验证结果分别记录于 `PACKAGING-AUDIT.json`、`BUILD-IDENTITY.json`、`NATIVE-SUMMARY.json` 和 `VALIDATION-RESULT.json`。安装包保留本地，未上传发布。
