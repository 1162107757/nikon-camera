## 变更

- 「人像 → 皮肤」新增全图自动识肤「磨皮」，与肤色并列，一个 0–100 强度，默认 0。无需选脸；识别状态可重新触发。沿用暗色/杏色工具区、撤销/重做、精确预览应用门槛和取消事务。
- 独立 `skinSmoothing` 保存到可选人像 v6，并保留原有肤色、面部和塑形。新强度为零时继续写旧 v4/v5，旧参数、序列化和像素公式不变。涂抹皮肤的磨皮继续使用既有区域柔肤/纹理状态。
- `SkinSmoothingFilter` 对识别出的皮肤使用原始行窗口及蒙版限制邻域权重；抑制小明暗瑕疵，细残差与强边缘采用更保守的混合。蒙版外、透明像素和 alpha 保持原值，不做全图模糊。缓存上限 64 MiB，支持逐行和行内取消；在肤色之后、祛痘/塑形之前处理。
- 草稿身份包含未准备蒙版的非零磨皮状态；最终应用须皮肤蒙版及最新精确预览就绪。现有逐张导出自动使用新草稿 profile。
