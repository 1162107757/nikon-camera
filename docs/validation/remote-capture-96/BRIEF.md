# 96 修复范围

Operate 模式，继承现有原型及 95 的原生布局，局部修复两个用户报告的问题，并执行用户新增的收纳要求：

1. 遥控页显示「相机已断开」，具体错误是「当前相机未开放尼康遥控会话」。两处初始化检查只接受厂商扩展 ID 10。新增的回归用例在未修复生产代码上重现了相同拒绝；Nikon 的 Microsoft/MTP 标识为 6 或 `0xffffffff`。用户设备的原始 DeviceInfo 尚未取得，因此不能断言其实际字段或实机已经恢复。
2. 编辑器「查看全部滤镜」的四小方块偏离按钮中心。空文字 Button 的左侧 compound drawable 仍受文字内边距定位；改为在原 48dp 触点和原背景内以 Gravity.CENTER 放置同一 19dp 矢量图标。不改变按钮形状、尺寸、相邻分类和行为。
3. 用户明确要求把底部「照片保存到相机／拍后传入 App」收进小齿轮。底部保存行移除；齿轮位于直方图左侧，替代右上重复的三点设置入口。保存到相机存储卡的只读说明和可选 JPEG 传入开关排在设置页顶部，释放竖屏取景空间并缩短横屏控制区。控制器与保存语义保持不变。

共同 Nikon 身份检查要求制造商为 NIKON／NIKON 开头的公司名称，扩展 ID 为 Nikon / Microsoft / MTP 已知值。保留原始无符号字段，不改写设备信息。身份识别不会赋予相机没有广告的取景、对焦或快门能力；通用相册接口及可撤销权限保持边界。

参考上游的身份处理：[libgphoto2 library.c](https://github.com/gphoto/libgphoto2/blob/master/camlibs/ptp2/library.c) 与 [ptp.h](https://github.com/gphoto/libgphoto2/blob/master/camlibs/ptp2/ptp.h)。独立编写本项目的 Java 判断，不复制上游实现。

与「按参考风格设计 App」已确认 96 排查所需文件归本任务持有，无并发修改／构建。保留 94／95 安装包、照片载入修复及其他编辑器行为。

验证环境仅为自有隐藏只读 Pixel_9 模拟器 emulator-5588 与内存 PTP/IP 字节夹具。编辑器图标截图使用真实 PhotoFilterEditor.createDock 的原生组件测试容器（未加载用户照片），不是完整照片编辑场景或用户实机截图。白色图标像素边界相对触点中心测量，分别验证 LTR／RTL 和字号／方向；该断言直接覆盖用户报告的偏移。

原生界面不运行 HTML/CSS detector。功能与图标证据在同一批验证中收集；不扩展为重设计、实体相机互操作或性能认证。本轮不操作实体手机／相机，不上传发布。

`8e61d0e0` 是追加收纳需求前已通过的候选，已经归档到 pre-settings-8e61d0e0，不能作为最终布局证据；其审核在用户追加要求后中断。新的当前 APK、矩阵和截图以本目录重新生成的身份记录为准。
