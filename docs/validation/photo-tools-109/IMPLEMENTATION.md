# 图片工具联合实现：109／0.22.0-beta

用户要求此前未完成的 1、2、3、4 一起处理。本轮扩展现有照片编辑工作流，继续使用照片为主体、黑色工具区和紧凑玻璃控件。

## 实现范围

| 项目 | 已接入的功能 |
| --- | --- |
| 局部蒙版 | 画笔、径向、线性渐变；曝光、色温、饱和度；羽化、反选、开关、增删；选区叠色和双指导航 |
| 取样修复 | 明确源点和目标点的羽化克隆，区域大小可调，重叠取样使用源块快照 |
| 降噪与纹理 | 明度／彩色双边降噪；确定性颗粒；暗角，保留 alpha |
| 透视 | 水平／垂直投影校正，与 EXIF、裁剪、旋转、拉直共用完整矩阵 |
| 成品预览 | 真实完整尺寸 JPEG 和编码前 PNG 对照；实际质量、尺寸与字节数；适应／100%／200%、平移定位，单张及批量选图 |
| RAW 显影 | LibRaw 0.22.3 读取传感器数据，完整尺寸去马赛克、相机／自动／手动白平衡、曝光与高光处理；保存 8bit sRGB PNG 或生成完整 Q100 JPEG 编辑副本 |

蒙版与修复是照片专属状态，进入 PED6 草稿、撤销／重做、切图恢复、缩略图、真实细节及导出身份。零效果区域保留编辑状态，但不改变旧像素身份。跨照片复制和配方不复制坐标区域；批量配方、滤镜和边框都保留目标照片已有局部状态，并通过完整 compare-and-replace 避免覆盖后续编辑。

PED1–PED5 读为空局部编辑并保留旧参数；PCR1／PCR2 兼容，PCR3 保存新增参数。原来的 13 个调节扩展为 17 个。所有新效果为零时保留原有渲染路径和身份。

RAW 是独立显影阶段，LibRaw 内部处理后进入 8bit sRGB 输出；现有 Java 编辑器继续处理 JPEG 副本，不宣称线性 16bit RAW 编辑链。原 RAW 保持不变。完整尺寸失败明确报错，不用内嵌 JPEG 或缩略图代替。引擎支持的具体机型与压缩格式取决于实际 LibRaw 解码器，不能以一张 NEF 推断任意 RAW 兼容。

## 主机与构建

- 局部处理 43,230 项检查：EXIF 1–8、三类蒙版、半像素克隆、alpha、取消、边界和 24MP 有界行处理。
- 降噪／纹理／透视 39,904 项检查；24MP 流式处理在 64MiB Java 堆完成。旧路径 10,209,032 像素对照一致。
- 编辑器、存储、构图、配方、曲线及复制共 692,684 项检查，包含新迁移／完整状态冲突 33 项，见 editor-host-final.log。
- RAW 设置与真实 DNG 结构主机检查 281 项。
- 四 ABI（arm64-v8a、armeabi-v7a、x86_64、x86）共 12 个库；64 位三库全部 16KiB LOAD 对齐。32 位自建库为 16KiB，官方 libc++ 为 4KiB，按实际记录。APK 使用提取式原生库安装与 zipalign -P16。
- APK 附带完整未修改 LibRaw 源码包、许可、桥源码和构建说明，原生库独立可替换；身份见 third-party/libraw/BUILD-IDENTITY.json。
