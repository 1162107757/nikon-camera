# 图片工具表面约定

Mode: Operate。保留 Huevia 黑色照片工作区、杏色强调、系统无衬线和现有毛玻璃材料，不重设全局品牌。

- 局部工作区优先显示完整比例照片；普通布局工具在底部，横屏在右侧。显示叠色独立于导出像素；双指导航与区域绘制区分。
- 工具名称一行，操作以短词表示：画笔、径向、渐变、修复；调节、区域、撤销、重做、叠色、适应。可见选择面与触摸区域分开，保持 48dp 操作目标。
- 透视用既有构图滑杆切换拉直／水平／垂直，不额外增加面板层级；原生菜单跟随编辑深色环境。
- 成品预览沿用细节页玻璃浮层：右上实际规格，左下缩放，比较胶囊内缩一致，图像不为说明文字让出大段固定空间。
- RAW 显影使用独立完整照片页，紧凑白平衡／高光／去马赛克选项和曝光滑杆；保存 PNG 与编辑副本作为明确输出，错误提供可重试状态。

最终验证和边界见 FINAL-VERIFICATION.md；原生图审不等于用户最终视觉批准。
