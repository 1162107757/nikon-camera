# 图片工具联合实现与验收

2026-10-27 用户要求将此前列表 1、2、3、4 一起处理。本轮目标为局部蒙版（画笔／径向／线性渐变）、取样修复、亮度／彩色降噪、透视、颗粒与暗角、真实 JPEG 成品预览及真正 RAW 显影。

基线为已发布 108；109／0.22.0-beta 为当前本地候选，108 线上制品和发布策略保留。

实现按文件归属并行，统一接入：PED6 草稿／PCR3 配方、照片专属区域状态、历史及完整比较、各个 Draft 重建入口、共享逐行像素处理与 EXIF 上下文、真实全分辨率导出。RAW 使用独立 LibRaw 0.22.3 解码／显影，完整传感器数据处理后输出 8bit sRGB PNG，另可生成 JPEG 副本进入现有编辑器；不把内嵌 JPEG 或半尺寸替代原始显影。

验证按有界两批：先完成模块及迁移／冲突的主机检查，再在一个独占 Android 模拟器上首批运行局部工具的普通／1.3 字号／横屏、真实导出预览和 RAW 引擎／Activity 探针，批量审看截图。将发现的问题合并修复，最多再做一批相应确认；验证失败、候选和原始证据均保留。不得以模块编译、合成 DNG 或单张 NEF 通过推断所有实体手机／相机支持。

最终交付需绑定最终 APK 的版本、字节数、SHA、签名、完整生产／原生输入、原生探针及每组结果；新增模式不能在 UI 看得见而在草稿、细节或成品中丢失。既有目录容量和相册位置修复继续保留。
