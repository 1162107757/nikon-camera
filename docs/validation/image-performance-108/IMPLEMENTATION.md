# 第一轮：大图体验与处理内存

108／0.21.9-beta 的图片处理改动，基线为冻结的 107／0.21.8-beta。2026-10-27 已在 beta 通道发布并启用强制更新，见 PUBLICATION.json；线上下载与本文测试的最终 APK 字节身份一致。

## 已接入的实现

- 细节页连续拖动改为一个在途请求与一个最新待处理视口。同一模式的中间高清瓦片可以及时显示；仅最新视口就绪才能标记完整像素。切换模式、暂停和关闭仍拒绝旧任务回调。
- 细节页文字、尺寸标签、选中背景与启用状态只在发生变化时更新，减少拖动时重复创建背景和触发布局。
- 毛玻璃在尺寸不变时复用两张位图、两组像素数组和绘图对象，成功采样后交换；失败保留上一张背景，关闭释放缓存。
- 大图预览解码在旋转／缩放产生新位图后及时释放不再使用的中间位图，保留原有采样、EXIF、缩放和舍入顺序。
- 调色配置预计算不随像素变化的参数；仅锐化路径只保留实际需要的一级半径缓冲。包含中频锐化或清晰度的路径继续使用完整处理。

## 已完成的主机验证

- 冻结 107 与新版渲染逐像素对照：9,881,352 个像素完全一致。
- 现有编辑器测试 692,651 项检查、空间滤镜 16 个场景／41,534,647 项断言及细节视口 57 项检查通过。
- 桌面 24MP 仅锐化流式处理三次中位数为 1461.101 → 1057.839 ms，输出摘要一致。这是特定算法基准，不代表手机整张导出耗时。
- 6000 像素宽的仅锐化行缓冲按分配公式从 17,848,384 降至 1,048,384 字节；这不是 App 总内存或峰值内存测量。
- 独立源码复核覆盖任务代次、位图引用、玻璃缓冲交换及异常路径，未发现本轮新增问题。
