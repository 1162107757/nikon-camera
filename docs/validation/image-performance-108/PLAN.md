# 108 大图体验优化

2026-10-27。基于冻结 107／0.21.8-beta，当前生产输入与 107 的 221 项身份一致。目标是改善细节连续移动和大图处理内存，同时保持相同渲染数学、像素结果及编辑／导出语义。

本轮范围：

1. 细节视口采用有界的在途／最新待处理请求，移动时持续补充区域，停止后完成最新视口。模式、页面、账号及源失效守卫保持；未完成当前区域时不能认证为完整 100% 像素。
2. 细节控件只更新真正变化的状态；玻璃采样同尺寸复用位图和数组，仍随图像位置更新。
3. 不变调色系数在不可变 profile 创建时计算，逐像素表达式顺序和模型身份不变。
4. 仅锐化时按实际滤波半径分配缓冲，不为零贡献的尺度分配工作集；旧新像素必须完全一致。
5. 编辑图解码后及时释放已被旋转／缩放结果替代的中间位图，保留相同变换与缩放步骤。

验证采用有界的专项：桌面内核旧新逐像素对照及时间观察，原生同一 107／108 探针比较 JPEG 解码、连续移动、最终真实像素与生命周期。普通字号手机配置检查交互；不重复 107 的完整视觉矩阵。没有实体手机连接时如实保留该验证缺口。
