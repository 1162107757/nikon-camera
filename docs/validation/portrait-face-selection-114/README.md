# 人像选脸短暂蒙版反馈 · 114 / 0.23.3-beta

按用户最新要求，每次点选人脸时用实际选区的半透明蒙版闪两下后自动消失。照片上不常驻人脸圆圈、编号或覆盖层。再次点选同一脸也重播，顶部选择按钮、切换菜单单选状态及无障碍描述仍同步当前人物。

反馈使用已有肤色选区权重生成的蒙版，异步生成完成后才开始计时：显示 220ms、隐藏 140ms、再次显示 220ms，随后清除。参数调节、大小调节、切换效果、缩放、适应照片及按住对比立即取消待生成或已开始的反馈。快速切换通过最新任务、选区匹配与重置代际防止旧蒙版回显；关闭窗口清除计时和位图。补选／擦除及手动蒙版开关保留主动检查选区的能力。
