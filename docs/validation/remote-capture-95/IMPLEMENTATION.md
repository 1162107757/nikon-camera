# 遥控拍摄 95 实现与验证

2026-10-24。用户批准的遥控拍摄原型由原生 Android Activity / View 实现，进入路径为「同步 → 相机照片 → 遥控拍摄」。视觉依据是 `docs/design-review/remote-capture-20261024`；界面没有嵌入 WebView。

## 实现

完整比例取景、小机型／图标、当前快门／光圈／ISO／曝光补偿、机身模式与电量、按钮／点按对焦、单次存储卡快门、最近照片及可选 JPEG 传入。亮度／RGB 直方图与显示的同一解码帧成对更新，可移动、收起或放大；中断、关闭、离线及旧帧均标明暂停。参数只读，由当前相机属性读取，不使用照片 EXIF 代替。

竖屏遵循已批准的上下布局；横屏保留左图与右侧 217dp 控制区，工具组覆盖画面且有暗色底，标题与机型保持紧凑。系统安全区、字号、返回、底部／右侧弹层由原生组件处理。

遥控能力通过当前 Nikon 设备广告信息开启。PTP/IP 的专用可撤销授权与相册现有单工作队列共用会话，普通相册读取 API 无快门或属性写入权限。进入时与传输／边拍边传互斥，退出结束取景并保留相机连接。拍后传入使用既有原图保存、验证和内容去重，不引入第二条 JPEG 保存链。

快门发送前持久化相机身份与基线文件列表；结果未知时保持禁用且不自动重发，重新连接后仍需显式核对。RAW 先出现时等待同名 JPEG，防止过早结束拍摄流程。明确拒绝不会形成未确认曝光；AF／快门拒绝提示保留 4 秒。离线可看缓存最近照片，未传入 JPEG 的按钮明确禁用并提示重连。

## 验证范围

- 纯 Java 遥控核心 36 项；既有 PTP/IP 4800 项；相册 889、能力 33、网关 22、项目保存 356、目录 100 项；RAW 结构 60、参考 8、控制器 39、传输 19 项通过。最后收尾未改这些主机测试覆盖的协议与存储核心。
- 最终安装包在自有隐藏只读 Pixel_9 模拟器 `emulator-5588` 验证。四种配置合计 372 次检查（竖屏 92、大字号 92、横屏 96、深色 92），是重复配置验证次数，不是 372 个独立场景。
- 每个运行校验实际安装 APK SHA，完整报告和 49 张当前原生截图由 `UI-MATRIX.json` 索引；历史失败及无效横屏证据保留，未混入最终矩阵。
- 每种配置仅向内存夹具发送四次显式快门命令，其中三次模拟曝光、一次明确拒绝。断线／核对／重连没有补发快门。未知结果核对、同帧统计、原图逐字节相同、RAW→JPEG 延迟、AF 坐标、拒绝提示跨轮询、离线未传入 JPEG 等均有断言。
- 生产 APK 无测试相机类、夹具标记和示例取景资源，见 `PACKAGE-BOUNDARY.json`。字体、方向、夜间模式和动画设置均按各运行回执恢复。

此处相机为内存 PTP/IP 字节夹具，常规取景为已注明来源的合成样片；横屏对比度图为纯色 JPEG。截图和检查不能证明真实 Nikon Z6II 固件兼容、Wi-Fi 路由／吞吐、持续帧率或完整 TalkBack 体验。参数设置、视频、B 门、连拍与定时器不在本次批准范围；必须另行进行实体 Z6II 联调后才能确认实机表现。本轮未操作实体设备，未上传或发布安装包。
