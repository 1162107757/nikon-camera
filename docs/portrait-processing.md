# 自然人像精修

131 / 0.26.0-beta 新增匀肤、去油光、自动祛痘建议、五官细修、方向补光、自然精修、自动塑形范围和批量人像同步，详见[人像精修扩展](portrait-upgrade131.md)。

本地完整照片进入编辑后，在「调节 → 人像」或更多菜单「人像精修」打开。人像工作区沿用完整原图比例；这里的人脸位置和笔触记录在照片朝正后、裁剪和透视前的坐标中。

## 操作

1. 打开人像后，先显示与一级调节工具一致的「皮肤」「面部」和「塑形」图标入口。点击「皮肤」才展开肤色工具，并自动识别整张照片露出的皮肤；直接选择肤色预设、自定义颜色和强度，无需选择人脸。自定义支持照片取色、效果预览和保存个人色卡。进入任一工具后，入口都会隐藏，不常驻底部切换。
2. 进入「面部」后，点「自动选脸」，或点「+」后在照片上拖出脸部范围。多人照片可以点按照片上的人脸或「选择人脸」分别调整。这里集中提供提亮、冷暖、红润、柔肤、纹理保留、光照和眼下阴影，处理范围跟随所选人脸。默认参数保持原像素。
3. 面部组的「选区」提供「选脸」「补选」「擦除」，「显示选区」呈现实际参与面部处理的蒙版。双指缩放和平移后可精细操作，画笔半径以原图短边比例保存。选中人脸时仅短暂闪动两次暖白色半透明蒙版，随后消失。
4. 「祛痘」点按瑕疵，工具从附近寻找边界颜色相近的参考纹理，保存明确的参考点，并在完整尺寸处理时进行颜色匹配和羽化融合。可缩小范围或「撤回祛痘」。
5. 「按住对比」查看本次人像处理前的照片。工作区内可撤销、重做、停用某张人脸或重置。工具页的顶部返回键回到人像入口页；入口页的关闭按钮取消整次人像编辑。系统返回先处理取色或未确认的颜色预览，再返回入口，最后关闭工作区。点「应用」将整次操作记为编辑器的一步撤销；取消关闭保留打开前的草稿。

返回入口再进入另一工具会保留已确认的肤色与面部效果、所选人物，以及上次使用的面部工具。顶部返回会取消尚未确认的自定义颜色预览，结束滑杆拖动并清理临时选区提示。「皮肤 → 更多」仍保留高级逐人肤色调节；普通全图肤色无需使用此入口。

## 皮肤磨皮

130 起，「皮肤」底部增加与「肤色」并排的「磨皮」。自动识别整张照片露出的皮肤，不需要选中人脸；拖动 0–100 强度淡化细小明暗瑕疵，尽量保留细纹理、皮肤起伏和明显轮廓。默认 0，不自动改变画面。点状态文字可以重新识别，识别不到皮肤时保留原画面。

全图磨皮使用独立参数，与肤色、逐脸柔肤、塑形互相保留；未参与磨皮的像素保持不变。沿用撤销、重做、按住对比、取消/应用事务、草稿和完整尺寸导出，批量导出也读取每张照片各自的设置。涂抹区域内的「磨皮」沿用原有区域柔肤参数与纹理保留调节，不改变旧草稿效果。

磨皮用于淡化小瑕疵，不保证自动消除明显痘痘、痣或大块色斑；需要精确去除时使用现有点按祛痘。新功能不改变原图文件。

从 122 起，人像支持[统一涂抹区域](brush-adjustments.md)。在调节页选中一个区域后进入人像，肤色、皮肤明暗冷暖与柔肤，以及面部光影都限制在该区域。皮肤功能同时结合自动识肤；普通曝光、曲线和 HSL 等仍可自由调整衣服或背景。人像工具内也可点击画笔创建或编辑范围，未确认的画笔及颜色预览继续保持可取消的事务。

## 塑形

128 起新增「塑形 → 瘦身 / 瘦腿 / 腿部拉长」，支持独立范围和强度、单腿 / 双腿、精确数值与撤销。默认强度零，需要把范围框放到身体或腿部；具体操作与边界见[人像塑形](photo-body-shaping.md)。有塑形时，皮肤、面部、涂抹和局部工具按塑形前的画面定位，完成后恢复塑形效果。

## 自动选区范围

全图肤色使用随应用附带的本地语义分割模型，同时提取面部皮肤与身体皮肤；露出的手、颈部、手臂和腿部不依赖成功选脸。识别不到皮肤时保留原画面并提示；可以点「重新识别」重试。自动皮肤蒙版的准备不占用撤销步骤，也不会创建人脸记录。

面部修饰先使用 Android 本地 `FaceDetector` 定位，再用随应用附带的关键点与语义分割模型细化脸部范围和五官保护。上述模型在本机运行，无需首次下载；手动添加、补选和擦除可修正面部选区。

清晰正脸最适合自动识别。侧脸、遮挡、特殊妆容、强烈色光或很小的人脸可能需要手动添加、补选或擦除。识别为空时保留真实空结果，并给出手动添加提示。重新识别会在确认后替换人脸选区和对应参数，保留祛痘；该操作可以撤销。

## 保存与一致性

- 每张照片保存独立的人像参数、多脸选区、笔触及祛痘参考点。旧局部编辑数据继续读取；无人像数据时保持原有序列化字节和效果身份。
- 人像状态与局部编辑共同参与编辑快照、账号隔离、草稿、撤销重做、缩略图、细节查看、真实导出预览及完整尺寸导出。异步结果须通过照片、账号、代次和起始状态校验。
- 跨照片复制基础调节会保留目标照片原有的人像设置；「我的配方」沿用只保存全局调色的规则，避免把某张照片的人脸坐标带到其他照片。
- 处理顺序为全局调色、局部蒙版和取样修复、人像精修与区域调节、塑形、构图与外加边框。原图文件保留，效果从原图及冻结设置重建。
- 完整尺寸柔肤采用有界行缓存；祛痘参考区域有内存上限；笔触采用空间索引。单张最多 12 个脸区、64 处祛痘，全部脸区合计最多 64 条笔触和 8,192 个轨迹点；超限有明确提示。
- 全图磨皮非零时写入可选人像 v6，内部保存强度和已有皮肤蒙版，并保留塑形。磨皮为零时继续写原 v4/v5 字节及身份；旧数据和旧效果不变。新磨皮在肤色处理后、点按祛痘和塑形前执行，缓存身份包含独立参数。

API 参考：[Android FaceDetector](https://developer.android.com/reference/android/media/FaceDetector)。真实人像 QA 夹具使用 [scikit-image 文档](https://scikit-image.org/docs/stable/api/skimage.data.html#skimage.data.astronaut)标明为公有领域的 NASA 宇航员照片，仅用于本地验证，不作为应用素材。
