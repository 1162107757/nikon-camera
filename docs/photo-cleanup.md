# 一键去灰

照片「调节」中的「去灰」入口会自动分析灰雾与颗粒，生成保守的初始效果。界面主要显示总强度、撤销／重做、重置和按住对比；「精细调整」展开去灰雾、降噪及重新分析。首次分析和最新预览完成后才能应用。取消或返回不修改主编辑器，应用作为一条主编辑历史。

总强度、去灰雾和降噪范围均为 0–100。自动结果的 100% 指应用当前照片估计出的处理量。总强度为 0 时保留分析与高级数值，但像素完全旁路；主菜单重置可清除这些保留状态。对比显示进入本次工具时的图像。

## 原图分析

`PhotoCleanupAnalyzer` 在后台验证原图 SHA256 和文件元数据，使用最长边不超过 512 像素、按 EXIF 正向处理的小样估计灰幕和大气光。降噪统计另外解码最多 9 个 96×96 的原图小块，`inSampleSize=1`，不从编辑预览推测原始颗粒。

选中涂抹区域时，小样和原像素采样均按同一原图正向坐标的画笔覆盖率筛选。透明及羽化边缘不冒充有效平坦噪声样本。没有足够平坦数据时，噪声置信度为零。小型分析结果按原图 SHA、算法版本、文件元数据和选区轨迹缓存，最多 8 项；缓存不持有图像。取消、关闭和重新绑定均阻止迟到结果写回。

## 渲染与保存

新增独立 `PhotoCleanup` 参数与固定 `Analysis`，原有 17 项滑杆、曲线、HSL、调色盘保持独立。全图处理先调用保边双边降噪，再按估计大气光和透射率恢复灰幕，之后进入滤镜与已有手动处理。现有胶片颗粒等后续效果继续保留。局部使用原有独立区域分支，在完成效果后仅按羽化蒙版混合一次。

去灰采用线性亮度空间中的受限灰幕恢复，通过统计置信度、逐像素高亮衰减和暗部防截断控制力度。噪声强度由原像素平坦区域的鲁棒高频残差估计，预览根据分辨率减弱降噪。处理逐行进行，不引入完整原图的附加内存缓冲；全尺寸导出、细节预览和区域分支进入同一渲染实现。

分析结果固定保存，避免预览尺寸变化时重新估计。草稿／保存版、配方、复制调整和撤销均保留它。复制分类为「基础调节与去灰」；跨图配方复用固定参数，点击「重新分析」才会根据当前原图生成新的结果。

仅有去灰存储状态时启用新格式：全图草稿 PED8、配方 PRC5、局部 v5；未使用去灰时继续写原格式。强度为零或置信度为零时，仍保留区域分析与版本身份。

这是基于统计的本地去灰和保边降噪，不是语义抠图或纹理重建。估计对平坦高亮背景、真实薄雾和相关纹理采取保守力度。效果应以实际照片及 100% 细节对比判断，合成样图的降噪指标不是所有照片的改善保证。
