# 人像精修扩展（131 / 0.26.0-beta）

## 入口与操作

「调节 → 人像」继续使用图标加文字入口，增加「自然精修」；窄屏可横向滑动入口。

- **皮肤**：在肤色、磨皮旁加入纹理保留、匀肤、去油光、自动祛痘。皮肤自动识别，不要求选择人脸。纹理保留控制全图磨皮的细节程度；涂抹范围沿用既有区域纹理参数。匀肤主要协调色彩斑驳，保留明暗起伏；去油光压低皮肤上的偏亮、低饱和反光。
- **自动祛痘**：寻找局部小红色瑕疵，默认排除中性暗色点。结果先列为可勾选的建议，再由用户点「修复所选」应用。「更多 → 逐处撤销祛痘」可以移除某一处，整次操作也可撤销。找不到合适候选时保持原图，仍可用点按祛痘。
- **面部**：新增眼神清晰、眼白净化、牙齿去黄、眼下修复、柔光补光。前四项根据实际五官关键点限制范围；补光支持拖动光点，以及左右/上下精确滑杆。眼部和牙齿修饰同时遵循此人脸选区里的擦除/恢复笔触；区域人像还会再受外层涂抹范围限制。
- **自然精修**：初次点击准备轻磨皮、匀肤、去油光、柔和补光和眼下修饰，默认自动组合强度 50。重新进入保留已有非零强度。手动设置继续独立保留，不自动塑形或改变五官几何。
- **塑形**：新增「自动定位」和「背景保护」。可选择检测到的人物，按轮廓与头部位置建议范围。半身照未确认腿部时保留原腿部范围并提示手动定位。背景保护针对显著长直线冻结保护权重，与滑杆、草稿、主画面选区显示和导出使用同一坐标映射。

## 批量处理

在「相册 → App 内」多选，点「批量编辑」，新增「批量自然精修」「同步第一张的人像设置」。前者给每张加入自然精修；后者使用第一张的皮肤参数和第一张人脸的面部参数，对各目标重新识别后应用。

每张读取自己的完整原图、草稿、肤色采样和五官位置。不会把来源照片的人脸位置、笔触、祛痘坐标或塑形范围复制给目标。目标已有的基础调色、裁剪、边框、涂抹区域和塑形保留。目标旧脸区按位置匹配后更新检测信息，已有手动修正继续保留。

处理显示逐张进度，可停止。写草稿前核对账号、原图哈希和完整旧草稿；中止或冲突会尝试回滚此次写入，保护后续独立编辑。完成后可以撤销本次同步；已被独立修改的草稿不会被旧撤销覆盖。检查后继续使用现有批量导出。

## 识别与数据

- 复用现有离线人体皮肤/关键点模型，没有增加生产模型、栅格或云服务。对脸部使用裁剪后的语义细化；手动五官保护以最小覆盖限制合并，避免重复相乘收缩选区。
- 以朝正分析图的完整像素哈希为键，最多复用四张照片的识别结果；缓存不持有源 Bitmap。皮肤、面部和身体定位共享已完成的分析，重复进入工具可复用。
- 新参数采用不可变 `PortraitRetouch`，全图与逐人参数分开。仅存在新状态时使用可选人像 v7，在原有字段之后保存独立参数及背景保护蒙版；没有新状态继续使用旧 v4/v5/v6 字节和身份。
- 匀肤/油光、五官细修和方向补光使用有界行处理，alpha 不改变，未覆盖像素保留。磨皮纹理默认 70 保持 130 的公式。补光方向是基于人脸形状的柔和明暗调整，不是三维场景重建。

## 边界

自动定位提供可修改的范围建议，不输出人体骨骼，也不会凭空补出画面外的腿和脚。背景保护优先降低长直线附近的变形，可能减少可见塑形强度；它不重建被身体遮住的背景。

自动祛痘使用保守的局部红色/明暗判断，不保证覆盖所有痘痘、痣或色斑；逐处确认和点按祛痘继续保留。小脸、遮挡、强色光和复杂姿态需要用户检查识别及范围。
