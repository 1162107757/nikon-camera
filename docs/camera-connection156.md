# 相机连接与返回 · 156 / 0.30.2-beta

用户要求：需要相机的操作在未连接时立即进入连接页；连接后能快捷返回触发操作的界面。

普通操作使用 `CameraConnectionRequest` 打开位于原 Activity 上方的连接工作页。标题和连接控件立即显示，不依赖预设库初始化；成功后显示带操作名称的“返回继续…”按钮。相机断开或仍在连接时不显示成功返回按钮。取消、顶部返回及系统返回回到原 Activity。

连接页按操作提供 Wi-Fi、USB 或两种通道；照片与遥控拍摄使用 Wi-Fi，USB 高级诊断使用 USB，相机详情支持两种。进入连接页只处理导航，连接动作继续经过原来的任务、权限和协议保护。

## 覆盖的入口

| 入口 | 连接完成后的行为 |
| --- | --- |
| 相机照片页签、照片列表及读取／下载／继续下载／套用预设前的连接检查 | 返回原同步页或照片操作页，下载和处理仍由用户发起 |
| 相机 RAW 页、刷新、下载 RAW | 返回 RAW 页面，重新读取列表 |
| 本地照片编辑器的 RAW 导出 | 先查询已缓存的 NEF；有来源记录但未缓存且未连接时，通过类型化回调进入连接页。回到原本地界面，再由用户发起导出 |
| 遥控拍摄入口 | 返回后打开遥控拍摄工作区 |
| 遥控拍摄断线后的重连、离线快门、传入 App、核对结果读相机 | 打开连接页，返回原遥控工作区；不重发快门、不自动下载 |
| 相机详情 | 返回后展示已连接相机详情 |
| USB 高级诊断中无设备或无访问权限的操作 | 进入 USB 连接页，回到原诊断 Activity；诊断、试传和写入需重新选择并确认 |
| 预设导入 | 保留已有待导入预设和一次性续接，连接成功后继续读取槽位，写入仍需确认 |
| 新建／继续边拍边传 | 立即进入连接页并保留项目意图，准备完成后一次性返回项目流程；取消清除待续接意图 |

连接页的 Activity 重建保留 Intent 中的操作名称和系统维护的返回目标；普通取消及成功返回保留原 Activity。相机重连仍会使原会话的照片句柄失效，控制器继续拒绝过期对象；下载恢复必须沿用已有的身份核对流程。
