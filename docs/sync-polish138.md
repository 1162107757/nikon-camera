# 页内切换和同步页简化

版本：0.28.1-beta（138）。

- 同一个底部导航页面内的来源、模式和功能切换直接更新内容，取消页面横移和入场淡化。例如在线预设／我的预设、相机照片／边拍边传／已下载、相册 App 内／手机。底部导航跨页面的入场效果保持原有规则。
- 同步“遥控拍摄”使用主题容器底色和正常前景色，连接按钮使用浅色强调底色，适配深色模式。
- “已下载”列表只用 12sp 常规次要文字显示 `x 张`，不再重复显示“已下载”标题。
- 移除已下载列表的星标筛选、缩略图星标及下载照片详情／更多菜单中的星标入口。历史仅看星标的筛选开关在初始化时清除，列表展示所有已下载照片。
- 星标记录不删除；项目和普通相册编辑工作区继续使用既有星标功能。

涉及生产文件：`MainActivity.java`（页内导航）、`AlbumPanel.java`（同步 UI 和下载上下文）、`app/build.gradle`（版本）。

验收：

- `tests/run-album.ps1`：相册控制器、相机能力、网关、边拍边传项目和下载进度回归通过。
- `tests/sync-polish-device-probe`：普通字体、1.3 倍字体、深色模式各 27 项断言通过。包括即时横向位移／透明度／动画状态、主题背景像素、旧筛选迁移、张数样式、星标入口隐藏和来源切换。
- 探针只在模拟器运行，使用隔离 JPEG 样本和内存星标；不连接相机，不触发远程拍摄。详情截图已避开系统全屏教学遮罩。
- 最终证据：`docs/validation/sync-polish138/final/`。真机视觉与触感尚未验收。
