# 涂抹区域调节

在照片的「调节」页，点击参数旁的画笔图标，或点击「局部」图标，打开作用范围菜单。

## 新建选区

1. 选择「新增涂抹区域」。新区域的参数从零开始，全图原有调整保留。
2. 单指在照片上涂抹。较明显的暖白色半透明蒙版立即跟随手指，抬手前就能看到实际选中范围；边缘随羽化设置柔和过渡。松手后闪两次再隐藏，继续涂抹时立即接管。
3. 调整「大小」「羽化」，用「擦除」修正范围。支持撤销、重做和清空。双指负责缩放、移动，不添加笔触。
4. 点「完成选区」。蒙版闪两次后隐藏，回到清晰的照片画面。

## 调整当前区域

当前区域名称会显示在参数区。选中「区域 1」后，可连续修改亮度、曝光、对比度、高光、阴影、白色、黑色、色温、色调、饱和度、自然饱和度、清晰度、锐化、明度降噪、彩色降噪、颗粒、暗角，以及曲线和 HSL。所有这些参数属于当前区域。

重新打开范围菜单，可以切回「全图」、选择其他区域、新增区域、查看或编辑当前选区、删除当前区域。切换查看范围不增加撤销记录；查看后未修改选区也不改变照片设置。每个区域独立保留参数，同一区域可包含多项调整。

查看或重新编辑已有选区时，也会先闪两次再隐藏。按住画面右侧的选区按钮可查看完整选区，松开、移出按钮或取消操作即隐藏。擦除、大小与羽化调整、双指缩放等操作会立即接管，不需要等待提示结束。系统关闭动画时，提示简化为一次短暂加强。

在当前区域中打开「人像」，肤色、皮肤提亮/冷暖/红润/柔肤/纹理以及面部光影也限制在涂抹范围内。皮肤功能会同时结合自动识肤，普通调节仍能自由作用于天空、衣服和背景。面部光影需要相应的人脸选区；全图或区域肤色不要求选脸。

从全图人像工具内进入涂抹，会先保留该人像工作区的暂存状态；新的区域人像点「应用」后一起提交。取消涂抹或区域人像，会回到原工作区；关闭原工作区仍可取消整次操作。

## 结果与保存

调节参数时不会常驻显示蒙版。选中涂抹区域后，画面右侧也可按住选区按钮查看范围，松开恢复照片预览；需要修改轨迹时再打开「编辑当前选区」。未涂位置保留本次区域处理前的像素；之前已经确认的全图或其他区域效果仍然有效。

区域轨迹与参数随照片、账号、草稿、撤销重做、细节预览及完整导出保存。原始文件不被修改。普通配方和跨照片复制仍沿用全图调节规则，避免把某张照片的选区坐标带到另一张照片。

原有径向/线性渐变和取样修复位于范围菜单的「渐变与取样修复」。
