# 编辑页工具精简（134 / 0.27.2-beta）

“按住看原图”由 142dp 的文字胶囊改为 22dp 对比图标，公共工具行只占 48dp。默认透明，按住时使用柔和桃色状态；触摸范围仍为 48×48dp。控制器继续负责按住、松开、移出、取消、辅助功能/键盘切换和不可用状态。只有编辑页启用该外观，其他预览卡片沿用原样。

右上角菜单移除 9 个重复入口：调节工具、局部与修复、人像精修、构图、曲线、HSL、保存当前配方、参数说明和重置当前参数。对应功能继续通过底部工具栏、配方页、参数标题及参数长按操作使用。

菜单只留下照片管理及整体操作：直方图、收藏、照片版本、查看照片细节、复制调整、撤销批量复制、保留滤镜重置调节、全部重置；草稿恢复与删除照片按原来的上下文条件出现。

本次不改变图像算法、模型、草稿或保存管线。安装包仅保留本地，未上传或发布。
