# Wi-Fi / USB 统一连接入口设计审核

用户要求新连接默认Wi-Fi，可选择USB；所有连接入口保持一致。三组均在同页切换方式，成功后返回调用功能，不自动打开相机照片。

- A：顶部双标签，推荐，沿用现有胶囊控件。
- B：连接方式卡片原地展开，步骤集中展示。
- C：大图标方式卡，USB入口更醒目。

每组左图为默认Wi-Fi、右图为切换USB后的示意状态。检测到Z6 II的卡片是设计示意，不代表实体USB目录读取已修复或验证。

使用内置image_gen生成，提示词保存在prompts.json，原图复制后逐字节核对，见review.json。用户已选定 A，产品连接页已按顶部双标签实现。Wi-Fi／USB 标签固定在顶部，内容在同页切换，USB 的底部主按钮负责检测或授权连接，设备卡片仅选择设备。

新建连接默认 Wi-Fi；已有健康 USB 连接显示实际连接方式并允许直接返回。方式切换、枚举取消不关闭已有连接。同步、预设导入、遥控、边拍边传、设置均复用同一连接入口。USB 目录修复另有自动化边界检查，具体 Z6 II 硬件效果仍需实测，不能把设计图当作修复证据。
