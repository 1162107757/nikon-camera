# 收起状态 · 三张方向设计图

用户追加要求：收起状态需要三张设计图供选择，无需为三个候选制作原型；此前已经完成的连接页和展开面板可继续按原型推进。

采用内置 ImageGen，分别生成三张，而非用 HTML 截图冒充设计出图。每张包含相同同步页背景的浅色、深色两个版本和按钮放大细节。用户随后选择 **B · 圆形图标**。A / C 作为已比较候选保留，现有原型已同步所选 B，不另做三份原型。

| 方案 | 文件 | 侧重点 |
| --- | --- | --- |
| A 文字胶囊 | A-capsule.png | 完整“相机工具”标签；易理解，约 124 × 48px |
| B 圆形图标 | B-circle.png | 52px 单个工具图标；遮挡最少 |
| C 贴边短签 | C-edge-tab.png | 约 90 × 48px；右边贴屏幕、保留“工具”标签 |

三张的精确最终提示词分别为 `A.prompt.txt`、`B.prompt.txt`、`C.prompt.txt`。参考图均为本目录上级 `review/android-light-sync-entry.png` 与 `review/android-dark-sync-entry.png`，即此前独立 HTML 原型的截图。生成图不是实际相机界面截图；图像模型可能对背景照片与文字做微小重绘，选择后以实际实现核对。

原生生成文件保留在当前聊天的 Codex generated_images 目录，项目副本保存在这里。未修改产品代码。
