## 1. Disposition — SHIP（限独立 HTML 设计评审）

新增全屏遥控范围可以交付本轮设计评审。原 P1 和可选对焦状态问题均已解决；本次只复核这些修复，未扩展打磨范围。此结论不代表产品接入许可、原生实现完成或真机批准。

## 2. Contract compliance

- 取景是独立全屏页，画面、四项参数和快门形成明确层级；Android / iOS 375px 的全局浅、深主题均保留摄影暗色界面。十张指定截图未见文字颜色继承、遮挡或横向溢出问题。
- 保留网格、照片计算的亮度直方图、点按对焦、最近拍摄、设置及八项只读参数；返回同步保留连接。实现与截图持续标明「取景演示」和本地演示值，没有把静态图片包装成真机结果。
- 就绪、暂停、等待、不支持、待核对和断开均有明确表达；快门静止，发送后只短暂反馈。待核对结果独立于取景状态保留，取景开关和返回后重新进入均不会解除快门禁用。

## 3. Material findings — exact evidence

**原 P1：resolved。** `screen.js:6` 现在把拍摄结果保存为独立的 `remoteCaptureUncertain`；`:7` 只归一化取景状态。取景切换（`:130`）及重新进入遥控（`:125`）均不写入该标记，仅「已核对相机，恢复拍摄」（`:132`）清除它。`remote-ui.js:7` 和 `:17` 持续据此禁用快门；点击对焦的保护条件也包含该标记（`screen.js:133`）。

`remote-uncertain-after-view-toggle.png` 与 `remote-uncertain-after-reentry.png` 都保留待核对提示、核对入口和禁用快门。`remote-recovery-check.json` 记录两条原旁路、关闭核对面板不清除结果、仅显式核对恢复快门的检查通过。没有遗留的已报告材料问题。

## 4. Optional polish

**原对焦状态问题：resolved。** `remote-ui.js:17` 的「对焦」按钮现在仅在取景就绪、已连接、无发送中任务且无待核对结果时启用；点击保护条件一致。更新的 `android-dark-remote-paused.png` 已呈禁用外观；定向报告覆盖六种状态的对焦可用性并全部通过。本轮没有新增可选打磨项。
