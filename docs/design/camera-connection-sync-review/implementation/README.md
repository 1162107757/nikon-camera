# 已批准设计的源码接入

用户在本聊天确认按设计接入，并额外确认照片列表上方的紧凑工具栏。收起入口采用 B（52dp 圆形玻璃）；遥控采用独立全屏取景。排序最终选择拍摄时间新/旧、名称升/降，两种都保留。

## 接入内容

- `camera_connection_view.dart` 承担 USB / Wi-Fi 分段、准备步骤、真实连接阶段与耗时、权限指引、取消、失败与重试展示。`camera.dart` 继续持有原有请求控制器；USB 授权与取消仍由原接口执行。
- 连接成功返回调用方；新连接回到同步时先不读取相机照片，需点击“浏览相机照片”。已有连接的原有浏览恢复行为保留。会话身份变化会清空旧目录、选择、分页游标与旧预览，避免混用照片句柄。
- `sync_tools_dock.dart` 为 B 圆形入口与三工具玻璃列表；空队列不显示 0 或空进度。有未完成任务才显示数量。离开同步时移除入口状态。
- 下载空面板按内容收缩；队列内容继续使用既有持久化、恢复、绑定与停止逻辑。
- `camera_photo_toolbar.dart` 左侧为相机照片和真实已读取数量，右侧为 RAW 开关、排序和选择。未读完的数量带 `+`，没有伪装成全部照片数量。双列照片显示文件名。
- `camera_photo_sort.dart` 只排序已经返回的元数据。时间读取真实 `capturedAt`；缺失/无效时间在两种方向均放末尾，名称采用数字自然排序，同值保持相机顺序。新页加入后重排，不新增目录扫描；预览跟随排序并按当前 handle 保持位置。
- 遥控从工具列表进入根导航上的全屏页，使用实际取景帧、机身参数、网格、直方图、对焦、暂停、最近拍摄和原有拍摄设置。没有加入示例照片或演示参数。退出等待路由动画及遥控租约释放后，才恢复同步请求。

221 修复中的 `run/request/capture/poll` 主体和快门互斥保留。`closeLease` 原有释放实现移至 `releaseLease`，外层只把原 Future 交给调用方等待；没有改 Java/iOS 根返回或相机协议。
