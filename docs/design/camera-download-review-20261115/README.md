# 相机照片下载按钮审核

用户已选择 **B / 图二：圆形下载按钮**，并提供附图确认。最终参考是 [approved-b.png](approved-b.png)，用户原图是 [user-approved-reference.png](user-approved-reference.png)。

使用内置 `image_gen` 生成三份审稿图，[完整提示词](prompts.json) 和 [原始来源/SHA](review.json) 已保存。三份原图保留于 drafts；A、C 未采用，不是实现依据。C 原图挤窄右列的问题只属于未采用草图，不会应用到照片网格。

实现约定：

- 仅在相机照片处于选择模式且有已选照片时显示圆形下载按钮，56dp，右上选中张数角标。
- 下载按钮在原52dp相机工具圆按钮上方，中心对齐，间隔12dp，避开底部四标签。
- 顶部只显示已选张数、全选和取消；删除顶部接收主按钮。
- 相机照片长按原地进入选择并选中该照片；点击其它照片继续多选。
- 三标签仍为一个连续灰色胶囊，内边距6dp、项间8dp、48dp触摸区；选中块约220ms滑动，减少动画设置时即时切换。
- 相机工具展开时临时让出下载悬浮位，关闭后恢复；保留当前选择，不缩窄/重排照片列。

设计图为界面示意，摄影样图用于审核；没有替换应用既有预设预览素材。227安装包验收状态另见 migration 文档。
