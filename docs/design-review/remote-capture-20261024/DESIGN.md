# 遥控拍摄 · 局部设计约定

## Overview

**状态：用户批准 PENDING；原生实现 DEFERRED。** 本文件只记录本目录浏览器原型的当前设计，供人工审核与后续交接。前述 token 仅在此提案范围内约束原型，不是已批准的全局规则；不得据此覆盖项目根目录的 DESIGN.md、PRODUCT.md 或现有 App。

本功能延续 Huevia 的暖白同步入口和黑色照片工作区。以完整画面为中心，让使用者依次完成看取景、看当前直方图与机身参数、对焦、拍摄、核对结果、可选传入。机型保持小字，快门占据主要操作层级。当前交付为设计稿，全部相机读数、连接和操作均为模拟。

## Colors

杏色主强调用于快门、选中工具和主要确认动作；深色文字用于杏色按钮。照片工作区以近黑背景、较亮面板和细分隔形成层次，暖白仅延续同步入口。成功与警示同时配合文字，不以颜色单独表达状态。RGB 曲线在放大面板中配有 R 红、G 绿、B 蓝标签。

已修正的同步未选中标签使用 #706A63 对 #EEECE7；FIX-MEASUREMENTS.json 记录对比度 4.52524:1。该结果只适用于这组实际颜色，不代表全界面对比度认证。

## Typography

采用现有 Android 工具界面的系统无衬线风格。主标题轻中粗，参数值使用等宽数字；快门、光圈、ISO、曝光补偿各有独立标签，不借照片 EXIF 冒充当前机身读数。横屏标题为 15px、参数值为 18px，标签仍为 11px；竖屏机型与电量基准为 11px，横屏为 10px。

审核工具的 1.3× 状态对声明可缩放的文字使用实际乘数：例如参数标签从 11px 增至 14.3px，横屏标题、机型与电量也按比例增长，通过重排和滚动容纳。不能为保住构图而缩小这些文字。此开关不是 App 新设置，也不等于完整 Android 系统字号适配；状态栏及小图部分辅助标记仍为固定字号，需在原生阶段继续验证。

## Layout

入口为“同步 → 相机 → 遥控拍摄”，保留原有四个根导航。竖屏从上到下排列紧凑标题、小机型／连接／电量、完整取景帧、四列当前参数、反馈行、最近拍摄／主快门／对焦、拍后传入开关。横屏把画面置左，参数以两列排列在右侧 217px 控制区，快门与传入操作同列安置。

原型设备画布分别为 390×844 与 844×390 CSS px；安全留白是审核用近似值。照片完整包含于可见矩形，当前 4:3 样片不代表 Z6II 流规格。原生布局应依据实际帧比例、窗口与系统安全区；黑边和浮层不参与对焦坐标映射。

图标可保持紧凑，但应用内语义操作目标以至少 48 CSS px 为原型意图。竖屏快门外形为 84px、横屏为 74px。浏览器尺寸通过不等于原生 48dp、实际触控可用性或无障碍验收。

## Elevation & Depth

工作区主要靠实底色和明度层次，避免工具与图像混在一起。直方图有近乎不透明的深色底。设置／详情面板以遮罩、上部圆角和轻阴影区分层级；横屏面板靠右并可滚动。外部设备预览使用中性、有偏移的阴影，它属于审核页面呈现。

## Shapes

主快门为同心圆，图标操作为圆形目标，最近照片与辅助操作使用小圆角。直方图是紧凑圆角仪表，设置为底部面板。保持摄影工具的克制外形，不用大相机图标替代小机型身份。

## Components

**取景与当前参数。** 参数默认只读，在机身调整；未知或未提供项目显示“—”。画面、参数、连接与拍摄请求分别具有状态。连接准备中禁用快门；连接断开后值置空、快门与对焦禁用。取景中断或用户关闭取景时明确覆盖原因，暂停点按对焦；若会话与拍摄能力仍有效，可继续读取参数和遥控快门。

**当前直方图。** 默认显示亮度小图，位于取景区左下留白；可拖动避开主体、顶部按钮收起或恢复、点按进入放大面板，在亮度／RGB间切换。小图初始 190×64px。拖动与点击放大区分，拖动、收起和切通道均不改变照片矩形或对焦坐标。没有新帧、取景关闭／中断、断线及拍摄等待新帧时，曲线淡化并标注“上次取景／已暂停”。真实实现需由同一当前预览帧与帧序号节流更新，参数另行判断新鲜度；不能用缓存缩略图或 RAW 分布冒充当前取景。

**对焦与快门。** 点图对焦只映射实际图像区域。原型模拟对焦完成、拍摄等待与拍后反馈，不以闪屏或动画当作拍成证据。快门请求进行中禁用重复操作；超时为“结果待确认”，不自动重发，先核对最近照片。拍摄中断线后仍保留不确定结果，重连不能清掉这一限制。

**拍后查看与传入。** 最近照片在确认拍成后更新，先明确“已保存到相机”。拍后传入初始关闭，开启后复用现有同步队列、当前项目与保存目标，避免重复下载。传入失败不得改称拍摄失败；只拍 RAW 的快门能力与 App 仅支持 JPEG 的传入限制应分开表达。

**设置与能力边界。** 实时取景、构图网格、拍后传入为独立开关。详情包含机身当前拍摄／对焦／释放模式和图像品质，未提供就不猜。原型面板使底层工作区不可交互，支持焦点圈定、Escape关闭和焦点返回；原生 Back、TalkBack、后台／熄屏及重建恢复仍待实现验证。返回同步的设计意图为停止取景并保留有效会话，未确认拍摄由共享任务继续核对。

原生快门必须等会话和操作／属性能力确认后才启用；Wi-Fi连接本身不足以证明可遥控。需在 Z6II 固件真机上验证取景、对焦、参数刷新与拍摄确认，并与既有传输共享连接调度。当前页面不承诺视频、连拍、B门、定时器、远程改参数或变焦。

## Do's and Don'ts

- 保持小机型、完整帧、独立参数条、明显快门和可移动直方图；依据实际机身能力禁用或隐藏不支持操作。
- 在人工审核前保持本文件为局部提案。内部 FIX-VERDICT.md 的 `ship` 仅表示两项 P2修正已通过有界复核，设计稿可供用户审核；不是用户批准或原生上线许可。该复核重看四张相关截图，其余15张未重审。
- 将 REVIEW-CHECKS.json 的83项通过结果表述为浏览器原型证据，不扩大为真实相机、实时流、RAW、性能、原生字号或安全区证明；本次文档整理没有新增检测。
- 19张设计截图加1张既有合成样片均为设计素材。assets/source-manifest.json 记录样片来自项目既有合成 PNG；直方图由同一样片的1,572,528个像素计算为64桶，不能称真实相机输出。
- 不在本轮修改生产源码、版本／APK、全局设计文档或既有 JPEG 修复。进入原生实现前仍须用户审核，并完成能力、帧新鲜度及拍摄结果核对机制。
