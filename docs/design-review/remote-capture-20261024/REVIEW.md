## 验证范围

`render-review.mjs` 在独立无头Edge中完成83项原型检查，见 `REVIEW-CHECKS.json`：对焦、重复快门拦截、拍摄确认、可选传入、返回同步、断线／重连／结果核对、弹层、横竖屏及1.3字号几何、至少48 CSS px操作目标、360px审核页无横向溢出。直方图有默认显示、隐藏、放大、RGB三通道、拖动、图像矩形不变化和旧帧暂停检查。结果为浏览器原型证据，不是原生48dp、真实触控／网络／相机性能证据。

19张设计截图在 `SCREENSHOTS.json` 中记录SHA；另有1张既有合成样片。20个栅格均保留来源／原生成提示元数据。图像未改原始构图，曲线由同一示例图片的1,572,528个像素计算；没有声称拿到真实相机直方图或RAW分布。
