# 遥控拍摄 · 设计 v1

状态：供用户审核的界面与交互原型，尚未获用户批准，不是已接入相机的 App。

## 目标与视觉依据

为 Nikon Z6 II 的使用者，在手机上完成“看取景 → 读机身当前参数 → 对焦 → 按快门 → 确认拍成 → 可选传入 App”。访客模式为 Operate。沿用当前 Huevia 暖白同步页、黑色照片工作区、`#F3B493` 杏色强调和系统无衬线字，不替换全局设计，不增加第五个根导航。

用户在设计过程中追加“还要可以显示当前直方图”：已并入当前取景页，支持亮度／RGB、小图拖动、放大、收起及取景暂停状态。原型曲线由当前合成示例画面的1,572,528个像素统计为64桶；只是静态设计数据，不能当成实时相机或RAW直方图验证。

本轮交付代码驱动的可点击设计稿与浏览器渲染设计图。所有操作是模拟，不调用相机、网络控制接口或真实相册；不会生成新 App 安装包。主机型保持小字，不用大相机图标抢画面。主画面与读数是明确标注的示例，源图为项目既有合成样片，来源见 `assets/source-manifest.json`。

## 页面和层级

- **入口**：同步 → 相机 → 遥控拍摄。原有相机照片、直播、已下载和四根导航保留。
- **竖屏取景**：紧凑标题／小机型与连接、电量；中部完整比例画面；当前快门、光圈、ISO、曝光补偿；反馈行；最近拍摄／大快门／对焦；拍后传入开关。快门视觉84px，对应原生至少48dp操作目标。
- **横屏取景**：画面在左，参数和快门重排到右侧控制区。保持图像比例，手指不遮主体；原生最终以窗口安全区和实际取景帧尺寸布局。
- **设置**：实时取景、构图网格、拍后传入 App 独立开关；只读机身参数明细；明确断开连接操作。原型的大字号设置仅为审核工具，不是 App 新设置。

## 状态与交互约定

| 情况 | 画面／参数 | 快门与恢复 |
|---|---|---|
| 连接准备中 | 显示连接状态，参数“—” | 禁用，等待能力确认 |
| 正常取景 | 完整帧；有来源的当前机身值 | 点击快门仅发一次；点图或对焦按钮可对焦 |
| 对焦中／完成 | 对焦框位于实际图像坐标；完成变为成功色 | 对焦成功与否由相机事件决定；原型模拟650ms完成 |
| 拍摄中 | 保留画面，显示等待相机响应 | 锁住重复快门；返回同步仍由共享任务核对结果 |
| 拍摄确认 | 显示“已保存到相机”，更新最近照片 | 可继续；默认不自动传入 App |
| 自动传入打开 | 拍成后再显示传入进度／完成 | 复用现有同步队列，不重复下载、不把传入失败说成拍摄失败 |
| 取景中断 | 清晰覆盖“实时取景已中断”；机身值若仍新鲜可保留 | 连接及快门能力仍有效时可拍；禁用点按对焦，提供重开取景 |
| 用户关闭取景 | 明确说明已关闭 | 保留读参数和遥控快门能力 |
| 连接断开 | 覆盖断线状态，当前值置“—”；不把旧图标成实时 | 禁用快门／对焦，提供重新连接 |
| 快门超时 | 结果待确认，不能直接宣告失败或成功 | 不自动重发；先查相机最近照片，确认后恢复 |

参数默认只读，在机身上调整。未知／不支持字段显示“—”；不以已拍照片EXIF填成当前机身参数。拍摄模式、对焦模式、释放模式与图像品质明细也是能力读取项，机身未提供时不猜默认值。

**当前取景直方图**：优先放在画面留白，空间不足时采用有实体底色的小浮层，可拖到不挡主体的位置。开关、模式切换或移动小图不改变取景图像矩形和对焦坐标。顶部直方图按钮收起／显示，点小图放大，放大面板切换亮度／RGB。参数和直方图分别有新鲜度：没有新帧、用户关闭取景、取景中断或连接断开时，旧曲线淡化并写明“上次取景／已暂停”；不能让停住的曲线仍显示更新中。拍摄中等待新帧也暂停曲线。实际实现应从当前预览帧节流计算，曲线随同一帧序号更新；不重新读取已拍照片EXIF、缓存缩略图或原始RAW去假装实时。

取景帧始终按实际宽高比完整显示；当前样片4:3只代表设计素材，不宣称Z6II实时流规格。对焦坐标需从显示图像的可见矩形映射到机身坐标，黑边与工具不参与。禁止依赖动画或闪屏判断相机确已拍成。

## 相机联调前必须保留的边界

官方 Z6II 支持 SnapBridge 遥控拍摄、取景和拍摄信息，不等于当前 App 的 PTP/IP 连接已经有同等能力。此设计是目标体验：实际实现需要读取操作／属性能力并用 Z6II 固件联调；无法支持的控制明确禁用或隐藏并说明。

- 网络已连接不等于相机会话或遥控能力就绪；先完成会话与能力确认，再点亮快门。
- 取景流、参数刷新、拍摄请求与现有预设导入／照片传输共用调度及所有权，避免相互抢连接。参数只做必要刷新；忙碌时遵守机身状态。
- 参数和画面有独立的新鲜度。画面超阈值就显示中断；连接失效后值置空。阈值由真机测试确定，不展示臆造FPS／延迟承诺。
- 快门完成须有机身响应及可核对的新照片身份；请求送达并非拍摄完成。超时先核对，不自动补拍。
- 拍后传入初始关闭；开启时使用当前拍摄项目及保存目标，不创建第二条自动下载观察链。只拍RAW时仍可拍，App仅支持JPEG的传入限制需要明确说明。
- 返回同步停止取景流并保留有效相机会话；后台与屏幕关闭、活动重建的停止／恢复策略由原生阶段定义并验证，不用静态原型作为保证。

第一版界面不加入视频、连拍、B门、定时器、参数远程修改或镜头变焦；避免把尚未确认的能力设计成可直接使用。

## 审核入口

`prototype.html`可查看状态、切换横竖屏与1.3倍字号；在画面内点按对焦、按快门、打开设置和最近照片。`board.html`为入口／正常取景／设置三屏，`?kind=landscape`为横屏，`?kind=states`为中断／断开／超时。

用户审核后才进入原生实现。当前生产源码、版本、全局PRODUCT/DESIGN及已有JPEG修复均不改动。
