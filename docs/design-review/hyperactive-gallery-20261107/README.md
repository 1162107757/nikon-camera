# Huevia · 四个主页设计提案

这是基于用户指定的 [Hyperactive 图库参考](https://dribbble.com/shots/27683076--Product-design-for-photo-gallery-mobile-app-Hyperactive) 制作的一份可点击网页原型，**仍待用户确认设计**。范围仅为预设、同步、相册、设置四个主页，以及主页内的来源、分类、选择和传输状态；图片处理沿用现有界面。

## 打开与评审

直接在浏览器打开 [index.html](index.html) 可查看四屏总览；也可在本目录运行：

```powershell
node .\serve.mjs
```

然后访问 [本地总览](http://127.0.0.1:8792/) 或 [单屏体验](http://127.0.0.1:8792/app.html#presets)。服务仅绑定本机。桌面总览以相同的 390×844 画框等比展示四页；宽度 601–1000px 时横向浏览，600px 及以下进入首个单屏，通过底部导航切换四页。

建议依次查看：

1. 预设的来源和分类切换；同步的相机、实时、已下载三种状态。
2. 相册的应用／手机来源、照片选择与浮动操作条；选择期间来源控件禁用。
3. 设置的分组层级，以及 320px 窄屏中的图库和底部导航。

主页以外的按钮显示“沿用现有界面”说明，不提供新的编辑、详情、导出或图片处理设计。照片、相机连接与传输进度均为演示数据。

## 设计与证据

[DESIGN.md](DESIGN.md) 仅记录本提案实际使用的暖白底色、摄影错列布局和白／炭黑浮动控件，不是生产设计规范。参考图仅供研究，未作为运行界面图片；本地示例照片来源见 [ASSETS.json](ASSETS.json) 及各图的 `.origin.txt`。未新增生成式位图；既有肖像素材的早期制作方式未重新认证。

[review/manifest.json](review/manifest.json) 记录冻结的五个源文件哈希和八张最终 JPEG：四页总览、六张手机状态及一张窄屏相册。手机截图实际为 390×843（CSS 视口 390×844 的截取舍入），窄屏为 320×720。静态证据使用 `capture=1` 关闭入场动效，正常原型保留过渡。

[浏览器记录](review/browser-checks.json) 覆盖四个主页、来源／分类恢复、选择、拖动切换、传输与导航间距及窄屏无横向溢出。[完整范围评审](review/finish-review.md) 提出一项小字对比度修复；[评分结论](review/verdict.md) 已确认该项修复解决，**其 `ship` 仅覆盖这项修复，不代表整套界面通过复审或用户批准**。[检测器说明](review/detector-notes.json) 记录唯一一次、基于初期较宽候选且已降级的正则检测（88 项）；不宣称自动检查全通过。

本交付不包含原生迁移、构建安装、云端发布，也不认证真实相机、账号、照片保存／删除或图片处理能力。
