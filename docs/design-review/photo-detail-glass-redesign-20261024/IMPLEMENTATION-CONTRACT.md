## 2. 骨架、字号与局部材料

原型390×844／844×390是布局参考，不是要在手机上绘制固定设备框。dp用于布局、sp用于字号；原型的28px状态栏、18px假homebar、演示手机圆角／阴影不进入App，改用真实systemBars／displayCutout／手势insets。

## 4. 底部五工具：具体布局与真实绑定

现有主接入为[PhotoFilterEditor.createDock](../../../app/src/main/java/cc/huevia/ui/PhotoFilterEditor.java)。五个panel共用同一宿主高度；切tab只改活动panel和下划线，不重建照片stage、不换Bitmap、不丢拖动中心。切组先结束当前连续拖动的一个撤销步骤，保持滤镜、手动、构图、边框与配方各自真实值。

### 滤镜

顺序固定为：48×fs头行 → 横滑卡片条 → 46×fs强度行。

- 头行：GRID为40dp视觉／48dp触达；在线／我的在同一个小分段底中，内部28dp视觉，3dp内距、2dp间隔、11.5sp文字；短状态10.5sp；分类11.5sp文字＋短下划线，在剩余宽度横滑。不能用两个独立56×48实色大按钮替代原型来源分段。
- 卡片：宽66×fs，照片52×fs高、名称22×fs高、图圆角10dp、2dp选中边、间距8dp；“80dp卡片条”包含留白，不能把图片本身画成80dp高。名称10.5sp单行；选中图边与字共同表达。
- 强度：11.5sp标签＋细轨滑杆＋右侧12.5sp百分值。0–100只影响滤镜，`无滤镜`禁用滑杆／显示无值，同时保留手动调节。若数值呈现为可点击按钮，须有真实精确输入，不能只做按钮外观。
- 功能沿用`setOnlineSource`、`selectCategory`、`showAll`、`choose`、现有profile与`strength`。来源、搜索、分类和完整选择框共用状态与真实计数；不能复制HTML中23／6款和随机分类计数。
- 保持按滤镜身份复用`FilterCard`，缩略图异步原位更新和scrollX；失败可重试、不支持禁选，不能用CSS滤镜或随机图片冒充NCP／NP3真实预览。
