## 已补齐的流程

1. **设置与输入。** 完整自然画布 JPEG 95 不受自定义 8192px 限制；分享为最终画布长边最多 2048px、质量 90、不放大；自定义长边为 640–min(8192, 完整长边)，质量 70–100。按完整数字串校验，允许首尾空格，不把小数、科学计数法或杂字符截成合法值。错误行内展示并禁用主动作；合法质量输入与滑块同步。小于 640px 来源禁用自定义。最终尺寸包含边框；质量 100 明示仍为有损 JPEG。
2. **保存状态。** App 成品、手机副本已核对存在、明确缺失、上次请求未完成、暂无法核对，以及“已发布但记录待修复”各自可达。默认存在时查看；未知先核对，不能直接当作丢失。缺失或 PENDING 只续接保存，不隐式新建；明确新副本才使用本次时间，普通保存保留拍摄时间。记录待修复分支只核对并补写记录，不再次发布。
3. **冻结与重试。** 接受时冻结来源、编辑、账号、实际规格、位置、新副本选择与发布身份。相同实际编码规格不因档位名称或目标而拆成不同像素结果；PENDING 与重试保留原发布请求。接受后改设置不会重定向任务。结果可看逐项原因，可单项或合计重试失败／未处理；成功项不重新执行，已生成成品的保存失败只补核对／保存。
4. **进度与停止。** 进度条只计已完成／总数，失败、取消和处理中均不冒充完成。停止先进入“正在取消，等待当前步骤结束”，下一安全阶段结束后保留完成项。收起不丢失取消收尾。重试合并成功后更新结论，不继续沿用旧停止文案。
5. **原始文件。** 可信完整 JPEG 与已关联 NEF 才显示对应入口。历史成品或 PNG 白底 JPEG 工作副本不冒充原图。独立确认明确忽略全部当前编辑及效果导出规格，保留已有元数据、可能含定位；独立选择位置，不覆盖原件、不清草稿、不把当前编辑标为已导出。NEF 仅示意已有原文件保存，不提供 RAW 显影。此原型没有复制、编码或发布动作。
6. **可操作性。** 所有手机内主动作、返回／关闭、设置、逐项详情、原始文件确认和结果重试均有事件。原生输入关联标签和错误说明；按钮有可见键盘焦点；模态限制背景操作、循环 Tab、支持 Esc 并返回触发控件。后台示意推进只更新设置页必要区域，保留正在输入的节点、焦点与选区。

## 审核工具与布局

手机框外的来源、回执和再次核对结果选择器是审核工具，明确不属于 App 功能。来源包含有框 6000×4500、小于 640px、小图历史成品、PNG 工作副本及 12000px 大图等声明夹具，用于验证规格边界；这些数字不是编码或设备实测。可手动推进阶段、自动演示或重置单台手机。打开模态时暂缓本地原型推进，明确不代表正式后台任务暂停。

标准／1.3 字号、320px 窄屏、横屏结构可组合切换。内容区滚动，主动作固定；低强调的原始文件入口位于内容区，避免横屏把可视内容挤空。长文案可换行，模态自身可滚动，支持减少动态效果偏好。**这些是 CSS 与 DOM 结构实现，尚未由浏览器渲染或像素对照确认视觉效果。**
