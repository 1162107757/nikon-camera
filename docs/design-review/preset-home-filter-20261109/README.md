# 预设首页筛选 · 三版设计提案

2026-11-09，用户明确要求预设首页筛选、自定义样式、尽量保留现有布局，仅提供三版图片审核。本轮未修改 Android 源码、版本、安装包或设备。

- **A · 右上浮窗**：[图片](A-anchored-popover.png)。推荐。筛选图标位于既有发现色彩／数量行右侧，点击展开就近浮窗，遮挡小、结构变化少。
- **B · 毛玻璃底部浮层**：[图片](B-glass-bottom-sheet.png)。底部短浮层，保留上半屏照片上下文，更方便单手操作；临时覆盖底部导航。
- **C · 右侧抽屉**：[图片](C-side-drawer.png)。分类两列及状态列表，适合未来筛选项较多时扩展；对当前两组条件占用较多，优先级低于 A／B。

三版统一用“风格”和“下载状态”演示，选择采用炭黑实底、白字与小型勾选，普通项暖灰色，提供重置／应用。类别来自现有 PresetCategories；下载状态为拟新增筛选能力，图片中的数量和样片为演示，不表示已实现过滤或实时结果。没有恢复已退役的 NCP／NP3 格式分类。

拟实现边界：保留搜索、加号、来源条、横向分类、发现色彩标题／计数、现有瀑布流与悬浮导航；筛选弹层覆盖内容而不挤压照片区。面板中先暂存选项，应用才更新，关闭丢弃未应用修改，重置清除当前面板条件；后续开发须结合现有在线全库搜索／分页，确保下载状态不是只过滤当前可见页。分类既有快捷入口与面板共用值，避免双重冲突；48dp 触摸范围、文字增大和小屏滚动需在原生实现中验证。

图片由内置 image_gen.imagegen 生成，[完整提示词](prompts.json)及[哈希清单](manifest.json)留档。视觉参考为冻结的 155 原生首页和既有四首页图板。C 曾生成一版更矮的侧卡，但背景误改为三列并更换来源文字，因此弃用；保留原侧抽屉作为第三种结构比较。效果图仅用于风格及交互审核，不构成像素精确的原生实现或测试证据。
