# 编辑页预设来源 · 设计审核

2026-11-10。用户希望在编辑界面直接选择“我的／在线”，并明确当前只有“三个点 → 全部滤镜”能切换。最新纠正为：**我的｜在线固定在前面，后面的分类可以左右拖动**。本轮仅出效果图，未改 Android 源码、版本、构建或设备；185 的 RAW 高光排查保持由原任务负责。

## 当前方案

- [我的效果](editor-mine-fixed-source.png)：左侧固定我的／在线小型来源控件，展示当前账号保存、导入的预设；照片缩略图显示对当前照片的效果模拟。
- [在线效果](editor-online-fixed-source.png)：相同位置切换到在线目录，未保存项用小型下载箭头表示，已保存／当前应用状态各按真实数据展示，不显示伪下载数。
- 同一行右侧为独立横向分类轨：全部、人像、风景、胶片、黑白、日常、夜景及实际自定义分类。左侧来源不跟随分类滚动，末端全部滤镜网格入口也固定。分类边缘可以轻微渐隐提示可拖动；不改成“全部”下拉，不换行，不增加一排或压缩照片。
- 下一行保留横向预设缩略图；当前预设只留一处小勾和薄边。照片、工具导航、撤销、对比、强度与导出沿用当前编辑器材料和位置，不将本次设计扩展为全编辑器重做。

## 交互约定

切换来源或分类只影响浏览列表，不改变当前已应用的预设、强度、历史或草稿。两来源分别记住分类和横向位置；已选预设不在当前来源时不伪造选中项，也不清空照片效果。横向分类、横向缩略图、强度滑杆各自持有手势，拖动分类不得误触来源切换或父级页面切换。

“我的”与预设首页我的预设采用相同账号可见范围，不把在线临时缓存冒充为用户主动保存；在线复用既有目录、下载校验和实际可预览能力。点击未保存项按现有准备流程处理，卡片内显示轻量进度，失败可重试，失败／关闭／账号或照片改变时不能覆盖原有效效果。未支持照片效果的预设需诚实标识，不能用任意内置滤镜冒充。

“全部滤镜”网格及三点菜单入口继续存在，用于搜索和展开浏览；来源、分类与主编辑条共享状态，不形成互相矛盾的两套选择。

## 视觉与实施边界

固定来源约 96–104dp，单项至少 48dp 触摸范围，绘制胶囊约 30dp、对称 3dp 内距；分类文字约 12sp，选中以细黄线表达，字体增大时减少可见分类而非缩小文字。右侧网格图标约 18–20dp，触摸目标 48dp。窄屏、1.3 倍字、横屏及读屏需要实施后在真实原生界面验证。

本次定位到 PhotoFilterEditor 已有 onlineSource 与 showAll 来源能力，现有主界面分类条却未直接暴露该切换；PresetSelectionPage 是另一个本地选择流程，本提案不误改它。视觉参考为已冻结 154 编辑器／全部滤镜原生图，图片中姓名、样例、模拟颜色与时间是设计素材，不是用户实时照片、真实预设效果或当前版本截图。新图由内置 image_gen.imagegen 生成，[完整提示词](prompts.json)与[哈希清单](manifest.json)留档；未运行原生验证，等待用户设计审核。
