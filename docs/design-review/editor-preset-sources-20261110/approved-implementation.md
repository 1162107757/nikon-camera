# 186 实施范围

用户已确认固定“我的｜在线”＋后方可横向拖动分类的设计，并额外明确要求选中圆角与边框圆角对称。

实现保留当前 PhotoFilterEditor 的实际来源、下载、筛选与全量选择器路径，将已存在但隐藏的来源切换露出为左侧固定小控件；右侧分类独立滚动，网格入口固定最右。同一行内完成，不增加默认／1.3倍字的工具区高度，不缩小照片。来源切换仍只改变浏览，不修改当前选中效果、强度、历史或草稿；全量选择器与主界面共用同一来源状态。提案中额外的每来源独立分类记忆不作为这次入口改动的要求，保留当前切换时重置分类与搜索的语义，避免扩大行为范围。

圆角与留白由单一原生控件共享计算：外轨、内选中框同心，内圆角为外半径减去同一内距，左右端内距与上下内距相等。文字位于实际选中框中心；普通／按压／焦点及我的／在线两状态均需检查。触摸目标48dp，文字12sp随系统缩放；窄屏只减少可见分类，不压缩标签或把分类改成下拉。
