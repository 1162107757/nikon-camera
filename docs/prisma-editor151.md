# Prisma 原型对应的原生图片编辑页（151 / 0.29.0-beta）

本轮按用户确认的 [交互原型](design-review/prisma-editor-20261107/prototype.html) 实现 Android 图片编辑页，并落实后续「滤镜间隙太近」的修正。滤镜卡片采用真实的 **14dp 外间距**，缩略图与名称完整显示；原型 CSS 和离线文件同步更新。

主页面采用照片延伸出的模糊背景、文件名居中的顶部栏、黄色导出按钮、黑色圆形工具和白底滤镜名称。工具顺序为「滤镜、调节、裁切、人像、边框」。在线／我的完整滤镜库、快速优化、配方和精细构图保留在文件名打开的照片菜单中；原有专用工具仍使用真实编辑管线。

原图对比改为可拖动的分割线，支持触摸、方向键与辅助功能进度操作。原图参考在后台按相同构图和边框准备，预览滑杆复用缓存；对比不会替换效果帧或改变草稿。裁切面板提供即时比例、90° 旋转和水平翻转，仍可进入原有精细裁切、拉直和透视。翻转设置参与历史、草稿、冻结身份及真实图像构图；旧草稿和未翻转状态的既有身份保持兼容。

原生 Android 使用真实状态栏、安全区、系统字体和辅助功能字号。短横屏保留沉浸布局与工具顺序；较宽设备使用现有侧栏结构。原型中的 CSS 滤镜和示意人像效果不作为正式预设或算法写入应用。

后续「箭头不够圆」反馈仅修改生产 `AppIcon.java`：撤销／重做使用 17×17 等宽高图标坐标边界、300° 正圆弧和连续圆头箭头，重做为精确水平镜像。位置、命中范围、处理事件及其他 304 项 UI 输入未变。原型 SVG 和离线 HTML 同步。
