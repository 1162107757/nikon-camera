# 原 Android 安装的资料迁出

这是同包维护构建 overlay，不改写原 `app/` 源文件、193 冻结产物或新版 `cc.huevia.next`。构建时从当前原 manifest 生成完整副本，保留原 application、权限、provider、相机活动及原桌面入口，另追加名为“旧版资料迁出”的第二个桌面入口。原功能仍可使用，新增入口通过系统文档选择器写 ZIP，原数据不清空。原预设、草稿、项目读取器的恢复动作运行在暂存副本上。

构建方使用现有原工程命令，追加 `-I cross-platform/legacy-android/overlay.gradle`。包名固定 `cc.huevia`，使用原 193 的下一版本号 `194`，必须使用与原安装**相同的签名证书**。发布构建前以 `apksigner verify --print-certs` 对照原安装包证书；旧文档记录 MD5 `945aa44a13dd8c10155ad0078edf698e` 仅作为历史证据，实际设备安装的证书仍须核实。不得通过卸载旧包来绕过签名不匹配。

导出包括本机可见预设、照片文件、当前账号的可读草稿、项目分类与默认预设。账号只导出 id/provider/username/nickname，不导出会话、密码、QQ token、AndroidKeyStore 材料。源安装不被清空。用户选定的 ZIP 保存失败时，系统文档提供者可能留下不完整文件，需删除后重试。

导出后在新版“设置 → 旧版资料迁入”选择 ZIP，先核对摘要、原生照片解码与资料清单，再迁入。同一账号的草稿与项目默认需在新版重新登录并核实账号 ID；旧会话不能作为新登录。照片、预设、草稿、项目使用版本化清单与独立 payload，每项记录字节数和 SHA-256。旧下载任务与系统相册发布许可不移植。
